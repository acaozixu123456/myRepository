# 3D 场景外包说明（给 Codex）

游戏改成「3D 冒险卡牌」，场景是**赛博朋克雨夜街区**（见 `docs/WORLD3D.md`）。你的任务分两类，都不碰引擎文件（`src/world/engine.ts / explore.ts / bake.ts / street.ts`、`src/art3d/{cat3d,pose,renderer,toon}.ts`）。

## A. AI 素材（图片）——决定画面质感的上限
放到 `assets/world/<类别>/`（新增目录），**每张 PNG/WebP、2 的幂尺寸、带出处说明**。每一批一个 PR，PR 里贴缩略图。
1. **外墙贴图（可无缝平铺）**：1024×1024，赛博朋克旧楼外立面——脏污金属板、老旧瓷砖、带水渍的混凝土、贴满贴纸的墙、管线 / 空调外机浮雕。每种 3~4 张变体；**必须无缝**（四边可拼接），不要带光照方向（光影由引擎打）。
2. **招牌 / 广告牌**：横版 1024×256、竖版 256×1024、大幅全息广告 512×1024。内容：猫猫世界的店铺和广告（拉面 / 当铺 / 网咖 / 酒吧 / 药局 / 「Be more than enough」式的反乌托邦标语的猫版），**汉字 + 少量英文**；背景纯黑或深色，霓虹发光感（会被当作自发光贴图 + 泛光）。
3. **远景天际线**：2048×1024 一张，夜晚巨型都市剪影（高楼、空中走廊、飞行器光点、全息广告光晕），**上方透明或渐变到深紫**，用来贴在场景外圈的柱面上。
4. **地面**：湿沥青（带水洼反光、油污、路标残影）1024² 无缝；地砖 / 排水沟盖 1024² 无缝。
5. **贴花**：涂鸦、海报、告示、污渍、裂缝（透明底 512²），各 10 张以上。
风格参考：用户给的暗调赛博朋克街景（湿地面反光、密集线缆与招牌、红 / 品红 / 青的霓虹）+ 日式微缩街角（暖色灰泥墙、红瓦、招牌）。**没有真人面孔**（广告里的人物用猫猫）。

## B. 3D 道具（代码）
在 `src/world/props/` 新建文件，导出 `Record<string, PropFactory>`（见 `props/index.ts` 的约定），再在 `index.ts` 里合并。要求：
- 用 `kit.ts` 的 `std()` / `glowMat()` 缓存材质，不要 `new` 一堆材质；一个道具 ≤ 40 个网格（引擎会合批）。
- 剪影清晰、细节丰富（管线、线缆、铆钉、小招牌），暗调金属 + 霓虹自发光点缀。
- 第一批清单：路灯（几种）、霓虹灯箱（竖 / 横）、排气管 + 蒸汽口、街边小吃摊、拉面屋台、投币机、公交 / 电车站牌、护栏、井盖、广告牌架（带钢架）、天桥 / 空中走廊段、空调外机群、屋顶水箱、天线群、晾衣架、纸箱 / 垃圾袋堆（猫猫世界：纸箱要多）、横幅 / 旗帜、无人机 / 飞行器（简单的悬浮车）。
- 每个道具在 `docs/WORLD_PROGRESS.md`（你来建）里一行：名称 / 状态 / 截图。

## 流程
和 3D 部件一样：一个 PR 一批，贴图，等 Claude 审核（通过 / 返修 / 换思路）。`npm run dev` 后打开 `/world.html` 看效果（`?dist=60` 拉远，`?team=…` 换队伍）。
