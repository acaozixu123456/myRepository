# 猫国志 · 设计总览（阶段一）

放置挂机卡牌 RPG 手游，玩法参考《三国志幻想大陆》，角色全部是猫猫。

## 1. 一句话
九命天子只剩最后一命，六大猫族争夺“九命印”。玩家是被召唤来的铲屎官军师，带着一群毛茸茸的将军挂机推图、养成、羁绊搭配。

## 2. 玩法循环（参考三国志幻想大陆）
| 层 | 内容 |
|---|---|
| 核心循环 | 挂机战斗 → 离线收益（小鱼干/经验/装备）→ 领取 → 升级突破 → 推下一关 |
| 战斗 | 5 人阵容（前排 3 后排 2），自动战斗；元气满 100 释放绝技，可手动触发；速度决定出手 |
| 招募 | 金铃铛 / 招福符抽卡，保底、阵营定向池、UP 池；重复转为专属碎片 |
| 养成 | 等级 → 突破 → 升星(★1~5，★5 觉醒) → 装备四件套 → 技能升级 → 羁绊 |
| 策略 | 阵营克制环 +7%/-7%；同阵营加成；8 组指定羁绊 |
| 长线 | 章节主线、爬塔、竞技场、公会、秘境、世界 Boss，每周轮换词缀 |

## 3. 耐玩性设计
- **三条搭配路线**：纯阵营（深加成）、混搭群雄（“乱世”按阵营种类加成）、羁绊队（指定组合）。
- **每只猫 4 个技能**：普攻 / 绝技 / 被动 / 觉醒，觉醒改变玩法而非只加数值（如周喵瑜“灼烧传染”、孟喵获“第七次”）。
- **联动机制**：灼烧×淋湿、符咒层数、图腾召唤、天命随机、元气操控等，鼓励研究组合。
- **有幽默的角色**：名字谐音、台词、喜好，让养成像“养猫”。

## 4. 美术规范
> **美术方向已改为 3D（见 [ART3D.md](ART3D.md)、[WORLD3D.md](WORLD3D.md)）**：猫猫是 Three.js 程序化卡通小猫（真关节骨骼 + 烘焙描边），战斗和 3D 探索街区共用；场景是赛博朋克雨夜街区（霓虹招牌、湿地面反光、泛光）。下面是沿用的角色造型规则；原 2D 矢量立绘保留为设定参考与无 WebGL 时的退路。
- 角色保持 Q 版约 2 头身，头大身小；不用照片质感。
- **描边用同色相的深色而不是纯黑**；阴影偏冷、高光偏暖；脸颊腮红、肉垫、鼻头为固定识别元素。
- 轻微的手绘抖动（位移滤镜）与纸张颗粒；色块之间不使用渐变糖水感。
- 每个阵营一套主题色与字徽（魏蓝 / 蜀绿 / 吴红 / 群紫 / 蛮橙 / 仙青），稀有度边框 SR 银蓝 / SSR 紫 / UR 金。
- 立绘由程序化矢量生成：`CatLook`（毛色花纹、眼型、耳型、尾型、体型、装束）→ SVG。修改一只猫只需改 `src/data/heroes.ts`。

## 5. 技术方案
- Web H5 + TypeScript，Vite 构建；后续用 Capacitor 打包安卓 / iOS。
- 美术管线：`src/art`（程序化绘制），`tools/gen.ts` 导出 SVG，`tools/export-png.mjs` 导出透明 PNG。
- 数据驱动：`src/data` 保存阵营、猫猫、技能、状态、羁绊，战斗引擎直接读取。

## 6. 阶段计划
1. **阶段一（当前）**：设定集 + 24 只猫猫立绘样稿 + 技能 + UI 风格板（`docs/showcase.html`）。
2. 阶段二：可玩原型：自动战斗引擎、主界面、阵容、招募、挂机收益。
3. 阶段三：养成与内容：升星觉醒、装备、羁绊、章节关卡与剧情、爬塔与竞技场、第二批猫猫。
4. 阶段四：动效音效、新手引导、数值平衡、存档离线收益、打包。

## 7. 目录

```
tools          截图、构建、文档与立绘导出脚本
docs           设计文档（00 总览 / 01 阵营 / 02 图鉴 / 03 战斗语言）+ showcase.html
assets/heroes  导出的立绘 SVG 与 PNG
```
