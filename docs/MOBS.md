# 杂兵外观对照

36 只杂兵分别手写 `CatLook`，数据在 `src/data/mob-looks.ts`，由 `src/data/units.ts` 的 `MOB_LOOKS` 与 `lookOf` 统一提供。每阵营按守护、先锋、神射、谋士、医者、刺客排列。毛色、眼型、耳尾与身宽逐只设置，不再按名字的哈希拼装。

制服保留阵营识别：魏为蓝甲旧银，蜀为绿布米白与温红缝边，吴为赤布铜褐，群为紫褐灰扣，蛮为橙带兽皮与素骨，仙为青白灰玉。身宽在 0.88～1.12，头宽在 0.96～1.07；没有披风、长披肩、旗背、光眼、冕旒、雉尾冠或亮金制服边。

## 既有款式与待确认差异

没有新增或改写美术款式。当前使用的头饰为 `none`、`helmetWei`、`scholarCap`、`sailorBandana`、`taoistCrown`、`lotusCrown`、`rattanHelm`、`featherHeaddress`、`fortuneHat`、`yellowBand`；衣装为 `armorWei`、`armorLight`、`vest`、`robeScholar`、`robeTaoist`、`rattan`、`tribal`；背饰仅 `none`、`gourd`、`scrollBack`；手持道具仅 `none`、`sword`、`bow`、`scroll`、`glaive`、`fan`、`herbs`、`mace`、`drum`。额外配饰限于 `scarf`、`tassel`、`bell`。

以下缺口已在 [Issue #26 评论](https://github.com/acaozixu123456/myRepository/issues/26#issuecomment-6106067033) 与[绘制限制补充](https://github.com/acaozixu123456/myRepository/issues/26#issuecomment-6106072586) 提问，替代方案等待 Claude 确认：

- 六名守护的纸箱、桃叶、荷叶、饭盘、藤编、蒲团盾均没有手持盾款式，当前保留空爪，不把骨棒当盾。
- 魏弩手的弩与蛮果弓手的枝杈弹弓暂用木弓；弓自带小铃和常规箭，软箭头材质与鱼骨弩需另有款式。
- 鼠耳帽、兜帽、叶帽、窄沿帽、药巾目前没有专用款式，分别使用圆猫耳加水师头巾、露耳夜行衣、叶色书帽、书生帽、布头巾或灰绿莲冠。水寨鼠兵始终是猫，鼠耳帽还未画出。
- 兽鼓学徒用现有羽冠与兽皮祭装；橙旗骨棒喵的素骨珠由兽皮服自带，额带和手中旗尚未画出。草鞋、补丁、桃花衣纹与藤绳也没有独立字段。
- 药箱、奶壶、粥罐、贝壳药具、炭炉、药篓、纸伞、锦囊排、绒绳和腰袋不能任意叠加，药具用 `herbs` 自带药葫芦及 `gourd` 替代，粮簿与锦囊题材用 `scroll`。不把替代道具写成已完成的专用物件。
- 猫毛没有二色玳瑁模式。紫羽游弓喵使用 `calico` 的棕色底、棕斑与黑斑，不用白底三花冒充精确的玳瑁模式。
- `coins` 固定带浅金闪星，`talisman` 固定带黄色光晕，`knives` 固定带三把空中飞刀；本版分别用空爪、卷轴与单剑，保证杂兵没有法器光效。普通小铃与弓上自带的铃仍沿用原画法，存在小面积黄铜色，无额外发光。
- 短剑、鱼骨匕与桃木剑当前都只能选现有单剑；它仍是原版银灰剑身，不宣称已绘出木质、圆头、布包刃或贝壳护手。
- 吴、仙刺客的提示包含斗篷，本版按 Issue 的朴素限制统一空背；群与魏兜帽也不拿披风来代替。
