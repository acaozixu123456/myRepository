# 玩法研究：挂机之外，还能长出什么

> 起因：玩家反馈“除了挂机，应该衍生更多玩法，更多创新玩法”。这里先看同类放置 / 卡牌游戏在做什么，再结合《猫国志》已有的系统（猫猫收集、阵营羁绊、模拟玩家社交、公会、首领）排出优先级。已经落地的标 ✅。

## 1. 同类游戏在“挂机”之外做了什么

| 方向 | 做法（资料来源） | 对我们的启发 |
|---|---|---|
| **自动推图 + 离线收益**（基础盘） | 放置卡牌的主流框架是“离线挂机 + 自动战斗 + 卡牌养成”三位一体，部分作品支持全自动推图与离线结算（[233乐园推荐文](https://www.233leyuan.com/post-detail/1974873854151571559)） | ✅ 已做「自动闯关」：战力够了自动挑战下一关，失败后要战力涨 3% 才再试 |
| **肉鸽 + 卡组构建** | 国风肉鸽卡牌构建、休闲卡牌骰子 Roguelike 都在被做（同上 App Store 检索结果）；放置里也有“战前决策”：战斗自动，但制作、训练、探索深度要玩家选（[Iris's Idle Log](https://www.incrementaldb.com/game/iriss-idle-log)） | 「纸箱迷宫」：一局 8 层，每层打完三选一加成，血量与元气带到下一层——决策发生在战斗之间，战斗仍自动 |
| **远征 / 派遣（多线并行）** | 远征队伍在离线时继续跑，玩家只主控屏幕上的一队，其余驻守；有的把“一个同伴上状态、另一个跟进爆发”做成搭配乐趣（[Partyforge Idle](https://store.steampowered.com/app/5166800)）。国内放置卡牌也常见“无尽试炼、英雄远征、神秘探险、古城迷宫”并行（App Store 商店页） | 「猫猫远征」：把闲置的猫派出去，按时长和阵营 / 职业搭配拿奖励，真实时间结算，下线也在跑 |
| **装备打造 / 词缀** | 每场战斗掉装备与材料，再强化、附魔、自定义词缀（[Idle Camp Tale](https://nodal.gg/game/idle-camp-tale-4874380)） | 已有装备系统，可往“词缀重铸”扩 |
| **放置 + 另一种循环** | 放置采矿 + 打怪，自动推进与离线奖励并存（[Mr. Mine Idle 介绍所在页](https://www.pocketgamer.com/ahead-of-the-game/throne-crusade-idle-rpg)） | 「猫窝」已是第二条循环（经营），可再加“种猫薄荷”等 |

> 说明：检索到的多是商店页与推荐文，缺少独立评测，所以上表只取“机制方向”，不引用其数值。

## 2. 我们的优先级

按“实现成本 / 与现有系统的复用 / 新鲜感”排：

1. ✅ **自动闯关**：基础盘，已完成。
2. **纸箱迷宫（肉鸽）**：复用战斗引擎（`UnitSetup.hpPct / energy / gear` 已支持跨场继承）、秘境的杂兵、世界首领的巨型敌人；新鲜感最高。
3. **猫猫远征（派遣）**：纯时间函数，和“墙上时钟”的设计一致；让收集的猫猫在不上阵时也有用。
4. （候选）**阵营共鸣塔**：每层只允许某阵营上阵，逼玩家养多阵营；**猫薄荷田**：经营循环；**公会战**：两公会按日对战，成员贡献累加；**装备词缀重铸**。

## 3. 纸箱迷宫（设计要点）

- 每天 1 次免费，可用金铃铛加 2 次；一局 8 层：第 1~7 层杂兵战，第 8 层首领战。
- 每层打赢后，从 3 个加成里选 1 个（全队生效，本局内叠加）：攻击 / 防御 / 生命 / 暴击 / 暴伤 / 减伤 / 速度 / 回复 / 元气。稀有度随层数提高；选项由「日期 + 局数 + 层数」种子确定，刷新页面不会换。
- **血量与元气带到下一层**；倒下的猫不会复活（除非选「休息」类加成）。全队倒下则本局结束。
- 奖励按“通过层数”结算：小鱼干、猫薄荷、同袍 / 登楼代币；打到第 4 层、第 8 层各有额外宝箱；记录历史最高层。
- 存档：一局进行到一半会保存（当前层、已选加成、血量），断线重连能接着打。

## 4. 猫猫远征（设计要点）

- 三条远征路线（短 / 中 / 长：30 分钟 / 2 小时 / 8 小时），按真实时间结算，离线也在跑。
- 每条路线有“需要”：例如「至少 1 只医者」「至少 2 只魏势力」「队伍总战力 ≥ X」；满足的需要越多，奖励倍数越高（鼓励养不同职业 / 阵营）。
- 出战的猫在远征期间不能上阵打主线（与“主力”形成取舍）；VIP 与月卡提高同时出征的队伍数。
- 收益：小鱼干 / 经验 / 猫薄荷 / 少量招福符；大成功（满足全部需要）有额外随机掉落。
