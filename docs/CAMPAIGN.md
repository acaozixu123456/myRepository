# 六章战役节奏

共 144 关，每章 24 关，第 6、12、18 关精英，第 24 关首领。普通关前半段一波、后半段两波，精英两波，首领三波；每波三至五只猫，前排站位 0～2、后排 3～4，末波精英与首领采用已有英雄。36 种杂兵覆盖六阵营与六职业，等级逐关增长，末章仍在英雄 120 级范围内。

各章第 9～16 关实际编入克制主焦点阵营的敌军，检验纯阵营队的压力；克制环保持魏→群→蜀→蛮→吴→仙→魏。焦点是主题倾向，不限制客串阵营。每章 8 条互不重复规则，共 48 关，赤壁反复交代淋湿、灼烧、火焰伤害与净化的组合。

## 推荐战力的冲突与暂定解

保留首关 300、末关 30000 与六个首领相邻跃升 12%。144 关共有 143 个间隔，扣除六个首领后剩 137 个，普通间隔倍率为 `(30000 / 300 / 1.12⁶)^(1/137)`，约增长 2.91%。采用 `powerCurve(chapter, index)` 跨章连续计算，最后四舍五入到整数。

Issue 同时要求每个普通间隔增长 4%～8%；即便全取下限 4%，终点也会到 `300 × 1.04¹³⁷ × 1.12⁶ ≈ 12.8 万`。两组要求无法同时成立，本次先保留首尾锚点，待 Claude 决定提高终章战力或接受较缓曲线；测试明确校验当前口径，未暗中跳过此冲突。

## 奖励、剧情与实现接口

常规小鱼干、经验与固定素材按全局关数非递减；首通基础奖励同样非递减，六次首领各追加本首领英雄碎片，数量为 5、8、11、14、17、20。全部首通带金铃铛，首领的额外碎片按同类里程碑比较成长，不要求下一普通关再发首领碎片。`rewards` 表示一次完成奖励，不是每分钟收益，后续挂机系统需统一结算频率。

`catnip_small`、`fishbone_small` 为 #14 已提出的道具 id；该 PR 尚未合入时测试使用显式白名单，目录存在时改为直接校验实际目录，首领碎片引用已有英雄。剧情在第 1、12、24 关分别挂 `c{章}_open`、`c{章}_mid`、`c{章}_boss_pre`，首领通关后挂 `c{章}_boss_post`；后三章剧情待后续内容任务。

阶段、预告与特殊规则现存契约只支持说明文字。`bossNote` 与 `rule` 是供 Claude 接入引擎的设计说明，未假定字符串已能驱动战斗，也未修改引擎或类型契约。
