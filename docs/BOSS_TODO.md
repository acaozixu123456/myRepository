## 共用接口

```ts

const rules = bossRuleFx(heroId); // RuleFx[]；每次返回独立规则与 act 对象
```

规则只认 `side: 'B'` 和指定英雄，未知英雄返回 `[]`。接口包含原第 24 关中带该 `hero` 的事件或预告，再加本次阶段；不带地利、全队开场词缀或章节支援猫。战役调用同一接口，原 Boss 专属条目只保留一份，尤其不能重复添加 `telegraph`，否则会连着预告、改打两次普攻。

### 时序与覆盖边界

- `hpBelow` 是严格小于，不是小于等于；每道血线独立计数。如果一次受击同时跨两道血线，两条都会触发。后续治疗回到血线上方不会重置次数。
- `hurt` 当前来自直接伤害结算，包括多段攻击每段和反击；持续伤害、付出生命等不会单独触发这些血线或七击规则。不能把它描述成“任何生命变化”。
- 引擎先判定本次伤害是否致命，再执行 `hurt`。致命一击可能留下护盾 / 状态事件，随后睡着清空它们；新获得的阶段盾或九命不能倒过来挡住这次致命伤害。已持有的九命可以挡住直接或持续致命伤害并保留 15% 最大生命。
- `turns` 按持有者的行动结束减一，晕乎乎跳过行动也会结算；反击在自身行动中跨线时，当次行动结束就计一次。它不表示全场整轮。董桌两道护盾独立，九命同名状态合并：同时跨过 60% / 30% 也只有一份；若原绝技九命剩 3 次，则不会被新申请的 2 次缩短。
- 预告只在元气 ≥100、未被毛线缠等效果禁用绝技、能够行动时发生。该次改打普攻；下一次仍满足条件的行动才施放绝技。期间受控制或元气削减可继续推迟；额外行动可能让施放发生在同一整轮，所以预告不是固定一整轮的锁。曹喵德只处理首次，其余三位每次处理。
- 阶段不会开启觉醒。当前 `waveSetups` 虽填写 `awaken: 'A'`，敌方英雄星级最高为 3；引擎要求至少 5 星才应用觉醒补丁。因此不能借董桌 A / 周喵瑜 A / 吕布丁 A 假称以下死亡治疗、灼烧传递、赤兔已在 Boss 战生效。

## 守塔适用范围

`kind === 'boss'` 时，按本层实际英雄 id 调用 `bossRuleFx`，无需复制六组数据。规则不依赖支援猫或章节号；孟喵获的血线九命与受击计数、董桌血线护盾等在对应英雄担任守塔首领时同样适用。普通层 / 精英层不添加。其他英雄不借用任何六章 Boss 的阶段。

保留现有轮换公式，首领池使用 `STANDARD_HEROES` 且排除 SR，SP 不参与守塔。名单增长会自然改变池长度与层号映射，规则始终按实际首领 id 复用，不把层号锁在旧24只名单上。当前38只常规名册下，十位 Boss 是：10 层张喵飞、20 层吕布丁、30 层水镜喵、40 层诸葛喵亮、50 层华佗喵、60 层左慈喵、70 层赵喵云、80 层吕布丁、90 层水镜喵、100 层刘喵备。当前 20 / 60 / 80 层分别复用吕布丁 / 左慈喵 / 吕布丁的共用预告，其他层返回空规则；将来已命名六章 Boss 排入守塔池即可自动复用。没有为凑六位而改轮换、强行更换英雄或套用不匹配的阶段。
