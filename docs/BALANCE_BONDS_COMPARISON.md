# 猫国志 · 命名羁绊开关对照

本次只改变模拟器的命名羁绊开关与报告口径。英雄、技能、阵营倍率和引擎代码没有改动，所有样本保留阵营同族机制。

三轮都基于主线 `e77248ce174dbe7d6010e560882ea57c44cdf8ff` 的英雄与引擎数据，包含 #20 的二十四只手工技能组及 Claude 已合入的调整。参数统一为随机主样本 3000 局、等级 60、五星、技能 10 级、随机觉醒、种子 `20261011`、最多 30 轮；每轮另跑克制探针 600 局、指定成员探针 1600 局，总计 5200 局。

| 工具版本 / 模式 | 随机主样本命名羁绊 | 克制探针命名羁绊 | 成员探针命名羁绊 | 总局数 |
| --- | --- | --- | --- | --- |
| 修改前基线 | 开启 | 开启 | 开启 | 5200 |
| 修改后默认 | 开启 | 关闭 | 开启 | 5200 |
| 修改后 `--no-bonds` | 关闭 | 关闭 | 关闭 | 5200 |

修改前先执行 `npm run balance -- --out .shots/balance-before.md`，保存原工具结果；改完后执行 `npm run balance`，生成 [默认完整报告](BALANCE_REPORT.md)，并执行 `npm run balance -- --no-bonds --out .shots/balance-no-bonds.md`。两个 `.shots` 文件是本次运行的本地原始记录。三轮的阵容、站位、觉醒与种子生成规则相同；开关不参与抽样。

## 随机主样本与成员组合

原基线与新默认的三千场随机主样本，全部英雄、主阵营及战斗节奏统计逐项相同；默认成员探针的数值也保持原样。修改默认克制口径不会改变其他样本的配置。

| 随机主样本指标 | 原基线 / 新默认 | 全部关闭命名羁绊 |
| --- | --- | --- |
| 平均战斗整轮数 | 9.36 | 9.41 |
| 达到 30 轮且双方清醒 | 128 / 3000（4.27%） | 129 / 3000（4.30%） |
| 引擎判定平局 | 3 / 3000（0.10%） | 2 / 3000（0.07%） |
| 首个绝技平均回合 | 3.07 | 3.07 |
| 没有绝技的局数 | 0 | 0 |
| 无法归因的持续伤害 | 0 | 0 |

关闭命名羁绊时仍保留指定成员齐全、替换一成员的分组，以观察英雄组合。例如桃园三位成员的独立探针在关闭时为齐全组 48/100 胜、替换组 40/100 胜，观察差 +8 个百分点；这个差值不代表桃园羁绊收益。两组英雄与阵营构成有变化，其他同族机制也继续生效。随机齐全组仅 16 次出场，仍标为低样本。

镜像换边复用同一阵容与种子，配对样本相关，不当作独立显著性检验。没有出场的英雄继续显示 `null` /「无样本」；少于 100 次仍只列低样本提示，不标为失衡。CLI 的随机主样本局数仍要求正偶数。
