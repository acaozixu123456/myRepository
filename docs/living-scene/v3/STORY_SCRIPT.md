# 雨あがりの路地 — 互动脚本

原创虚构日常故事。默认仅显示日语与回应，翻译及解释按需展开。无正误判定、积分、计时门槛或外部生成调用。

## 便当店

### greeting

雨がやんだね。<br>
少し、休んでいく？

雨停了呢。要不要在这里歇一会儿？

解释：「休んでいく？」是“歇一会儿再走吗”。「〜ていく」可以表示先做一件事，再离开这里；「少し」让邀请显得轻松，不强留对方。

- もう少し、ここにいてもいいですか。 — 我可以再待一会儿吗？ → stay
- ちょっと濡れちゃって。 — 我有点淋湿了。 → wet

### stay

もちろん。<br>
急がなくていいよ。

当然。用不着急着走。

解释：「急がなくていい」是“不必着急”，比命令别人慢下来更柔和。「もちろん」就是“当然”。

继续 → introduction

### wet

あら、袖まで。<br>
よかったら、このタオル使って。

哎呀，袖子都湿了。不介意的话，用这条毛巾吧。

解释：「濡れちゃって」是「濡れてしまって」的口语形式，带一点无奈。「よかったら」给对方留出婉拒的余地。

继续 → thanks

### thanks

ありがとうございます。助かります。

谢谢您，真是帮了大忙。

解释：「助かります（たすかります）」很适合回应别人递来毛巾、替你带路这样的小帮助，比只说谢谢多一层“正好帮到我”。

继续 → introduction

### introduction

私は志乃。<br>
この店、母の代からやってるの。

我叫志乃。这家店从我母亲那一代就开着了。

解释：「母の代から」是“从母亲那一代起”。「やってる」在这里是「やっている」的口语，指经营店铺。

- いい匂いがしますね。 — 闻起来好香啊。 → food
- 静かな通りですね。 — 这条街真安静。 → street

### food

コロッケ、さっき揚がったところ。<br>
雨の日は、いつもよりゆっくりなの。

可乐饼刚刚炸好。下雨天，店里的节奏总会慢一些。

解释：「〜たところ」表示刚刚完成。「揚がる（あがる）」在这里指食物炸好了，和雨停的「上がる」读音相同，写法不同。

继续 → invitation

### street

雨のあとだけ、少し静かになるの。<br>
いつもは、もっとにぎやか。

只有雨后才稍微安静些。平时要热闹得多。

解释：「雨のあとだけ」强调“只是雨后”。「にぎやか」形容人多、有生活气息的热闹，并不一定是吵闹。

继续 → invitation

### invitation

帰る前に、路地を見ておいで。<br>
雨のあとって、きれいだから。

回去前，去看看这条小巷吧。雨后的时候，很好看的。

解释：「見ておいで」是亲切的“去看看再回来”。「雨のあとって」里的「って」在口语中用来提出话题。

回到街景；此处完成

### return

おかえり。<br>
何か、見つけた？

回来啦。发现什么了吗？

解释：「おかえり」不一定只能在家里说。刚刚让你出去走走的店主这样迎接你，会让小店像一个可以返回的地方。

- 水たまりの中にも、灯りがありました。 — 水洼里面，也有灯光。 → reflectionReturn
- 雨のあとって、いいですね。 — 雨后的感觉，真好啊。 → rainReturn

### reflectionReturn

そう。一つの灯りが、二つになるの。<br>
それ、私も好き。

是呀，一盏灯变成了两盏。我也喜欢那个。

解释：「一つ、二つ」读作「ひとつ、ふたつ」。「それ、私も好き」把对方的发现轻轻接住，没有变成讲解。

继续 → tomorrow

### rainReturn

気づいてくれて、うれしい。<br>
毎日見てても、飽きないの。

你能留意到它，我很开心。就算每天看，也看不腻。

解释：「気づく」是察觉到。「〜てくれて、うれしい」表达对对方所做的事感到高兴。「飽きない（あきない）」是不会厌倦。

继续 → tomorrow

### tomorrow

明日も、この時間にはいるよ。<br>
よかったら、また寄って。

明天这个时候，我也在。愿意的话，再顺路来吧。

解释：「寄る（よる）」是顺路到访。「また寄って」比正式的“再次光临”更像熟人之间的邀请。

- じゃあ、また明日。 — 那就，明天见。 → farewell
- また、この道を通ります。 — 我还会经过这条路。 → farewell

### farewell

うん。足元、気をつけてね。

嗯。脚下小心。

解释：「足元（あしもと）、気をつけて」省略了助词「に」。说的是眼前湿滑的石路，也是一句送别时的关心。

回到街景；此处完成

## 湿路倒影

### light

水たまりに、灯りが映っている。

水洼里映着灯光。

解释：「水たまり（みずたまり）」是地面上的积水。「映っている（うつっている）」描述影像正映在水面或镜子里。

继续 → look

### look

見上げた灯りより、<br>
少しだけ、ゆらゆらしている。

比抬头看到的灯光，多了一点轻轻的摇曳。

解释：「見上げる」是抬头看。「ゆらゆら」形容缓慢摇晃，像水面里的光、微风里的枝叶。

- もう少し、眺めていたい。 — 想再静静看一会儿。 → linger
- 踏まないように、歩こう。 — 走的时候，别踩进去。 → step

### linger

何もしていないのに、<br>
少し、落ち着く。

明明什么也没做，心里却慢慢安定了。

解释：「眺める（ながめる）」通常是放松地看一段时间。「落ち着く（おちつく）」可以说情绪平静下来。

继续 → memory

### step

石の端を、ゆっくり。<br>
靴の先に、冷たい空が近づく。

沿着石头的边缘，慢慢走。鞋尖旁，清冷的天空近了。

解释：「〜ないように」表示为了避免某事。「端（はし）」是边缘；这里的天空是水中的倒影。

继续 → memory

### memory

この灯りのこと、<br>
あとで志乃さんに話そう。

这片灯光，待会儿讲给志乃听吧。

解释：「あとで」是稍后。「話そう」是「話す」的意志形，可以表示自己作出的决定。

回到街景；此处完成

## 门前暖灯

### on

まだ、灯りがついている。<br>
お店、開いているのかな。

灯还亮着。店是不是还开着呢。

解释：「ついている」在这里是灯开着。「〜のかな」是轻声的自言自语：不知道是不是这样呢。

继续 → ask

### ask

「まだ、やってますか。」<br>
声をかけるなら、この一言で。

“请问，还营业吗？”想开口问的时候，这一句就够了。

解释：「やってますか」是「やっていますか」的口语。对小店询问是否还营业很自然；更礼貌可以说「まだ営業されていますか」。

- まだ、やってますか。 — 请问，还营业吗？ → answer
- この灯り、あたたかいですね。 — 这盏灯，感觉好温暖。 → warm

### answer

はい、どうぞ。<br>
今日は、あと少しだけ。

嗯，请进。今天还会再开一小会儿。

解释：「あと少しだけ」表示“只剩一点时间”。店家这样回答时，通常是说离打烊还剩一点时间。

继续 → sign

### warm

雨の日は、早めにつけるの。<br>
帰ってくる人に、見えるように。

下雨天，我会早些把灯点起来。让回家的人能看见。

解释：「早めに」是比通常稍早。「見えるように」是为了让人能看见。和「見る」主动去看不同，「見える」侧重看得见。

继续 → sign

### sign

「営業中」は、お店が開いている合図。<br>
この灯りも、そんな合図かもしれない。

“营业中”是店开着的标志。这盏灯，也许是一样的信号。

解释：「営業中（えいぎょうちゅう）」常见于店铺挂牌；相对的「準備中（じゅんびちゅう）」表示暂不接待。下次路过小店时，可以留意这两个词。

继续 → home

### home

灯りが一つあるだけで、<br>
通りの感じが変わる。

只是多了一盏灯，整条街的感觉就变了。

解释：「〜だけで」是“仅仅因为……就……”。试着把今天刚看到的「灯り」放进去，而不必背一整条抽象句型。

回到街景；此处完成

## 雨后枫叶

### colour

雨に濡れると、<br>
葉っぱの色が濃く見える。

被雨打湿以后，叶子的颜色显得更深了。

解释：「葉っぱ（はっぱ）」比「葉」更口语。「濃く見える」是“看起来颜色更浓”，描述感受，而不必判断叶子真的变了色。

继续 → season

### season

秋も、少しずつ深まっている。

秋意，也在一点点变浓。

解释：「秋が深まる」是常见的季节表达。「少しずつ（すこしずつ）」是逐渐、一点一点，正好适合这条安静的小巷。

- 紅葉って、きれいですね。 — 红叶真美啊。 → red
- もう、秋なんですね。 — 原来，已经是秋天了啊。 → autumn

### red

同じ赤でも、<br>
一枚ずつ、少し違う。

即使都是红色，每一片也略有不同。

解释：「紅葉」说秋叶变色时常读「こうよう」；「もみじ」也指变红的叶子，尤其让人想到枫叶。「一枚（いちまい）」用来数叶片这样的薄片。

继续 → wind

### autumn

帰り道に、季節に気づく。<br>
そういう日も、ある。

走在回家的路上，才忽然察觉季节。有时，就是这样。

解释：「もう〜なんですね」带有现在才意识到的语气。「そういう日もある」是“也会有这样的日子”，很平常，也很温柔。

继续 → wind

### wind

風が通るたびに、<br>
枝先が、ほんの少し揺れる。

每当风经过，枝梢就轻轻动一下。

解释：「〜たびに」表示每当。「ほんの少し」是只有非常一点点；用在这里，比“大风吹动”更贴近眼前的动作。

继续 → keep

### keep

持って帰る代わりに、<br>
この色を、覚えておこう。

就不带回去了。把这个颜色记下来吧。

解释：「〜代わりに」是用另一件事代替。「覚えておこう」是打算记住，留待以后。

回到街景；此处完成

## 远处小巷

### distance

この先は、どこにつながっているんだろう。

这条路的前面，会通向哪里呢。

解释：「この先」是前方。「つながっている」表示相连。「〜んだろう」适合自言自语地猜想，没有在要求别人立即回答。

继续 → voice

### voice

「その角を曲がると、小さな橋があるよ。」<br>
店の奥から、志乃さんの声。

“拐过那个街角，有一座小桥。”店里传来志乃的声音。

解释：「角（かど）を曲がる」是转过街角。听到「その角」，可以顺着对方的目光看看街角。

- どんな橋ですか。 — 是什么样的桥呢？ → bridge
- 今日は、ここまでにします。 — 今天，就走到这里吧。 → stay

### bridge

小さな赤い橋。<br>
晴れた夕方は、水がきらきらするの。

一座小小的红桥。晴天傍晚，水面会闪着光。

解释：「きらきら」形容细碎闪光；和倒影的「ゆらゆら」对照，前者偏光，后者偏动作。

继续 → tomorrow

### stay

それもいいね。<br>
濡れた石、滑りやすいから。

这样也好。湿石头容易打滑。

解释：「ここまでにする」是在这里告一段落。「滑りやすい（すべりやすい）」表示容易打滑；「〜やすい」接在动词词干后。

继续 → tomorrow

### tomorrow

橋のそばに、花屋があるの。<br>
明日、まだ気になったら。

桥旁边，还有一家花店。明天，如果你还想去看的话。

解释：「気になる」是让人在意、想知道更多。「まだ気になったら」把下一次散步留成邀请；不用急着把今天没走过的路全部走完。

继续 → return

### return

今日は、この灯りのところへ戻ろう。

今天，先回到这盏灯的旁边吧。

解释：「戻ろう（もどろう）」是“回去吧”。回到便当店，志乃会接住你刚刚在小巷里的发现。

回到街景；此处完成
