# 来源与制作记录

用户授权使用 Codex 内置图像生成，要求延续现有雨后街景、增加店内与街角钱汤并保持连续性，随后明确要求新增画面动起来。

本轮三张图全部由内置 imagegen 生成，无外部付费生成 API、素材购买或第三方照片。便当店内和钱汤门前均以项目 Cat V2.1 的 `hero-clean.png` 为建筑材质、画风、同一晚光线参考；浴场以新钱汤门前图为参考。不是对用户住宅照片的复制，也未把住宅或监控照片打包进本分支。

生成提示词完整保存在 `art-source/living-scene/chapter1-v1/generation-prompts.json`。模型结果原样存为 PNG，并保留 SHA-256、实际像素与字节数于 `assets.json`。没有用普通插值冒充高分辨率原画。

这些文件作为生成的项目资产交付，不将其错误标记为第三方 CC0 素材，也不宣称模型输出具有排他版权。沿用的雨后街景、猫与音频来源见既有 V3 / Cat V2.1 交付记录；Three.js / postprocessing / three.quarks 等既有依赖和许可证不变。

动态为本轮编写的原始 WebGL 着色器：使用软区域、噪声水汽、纹理小幅重采样和轻缓光强变化。不是播放预生成视频；录屏是 Chrome 页面真实输出。PNG 是平面原始源，未交付多层 PSD 或新的深度图。场景对白是本轮创作的虚构内容，志乃沿用既有角色；拿铁 / ラテ来自用户明确确认。
