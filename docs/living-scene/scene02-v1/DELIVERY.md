## 构图与取舍

前景仅保留沙发、书与桌面边缘；中景以窗帘、暖灯、木窗台构成生活空间；远景由阳台栏杆、低层住宅/道路、中远公寓与天空余光分出层次。窗外为虚构普通日本住宅区，没有旅游地标。

最初生成的猫明显偏大，因此未采用；最终 Hero 将拿铁和坐垫一起缩小。猫身约占画宽 9%，处于右下区域，侧背向观察窗外，主视觉不使用正面卖萌姿态。猫/坐垫已融入主图绘画和灯光，不是照片抠图。局部图单独放近供美术观察，不改变 Hero 里的比例。

建议先看**默认 Hero**：窗外清晰度比较克制，室内灯光与窗景的关系更平衡。清晰版用于判断建筑细节密度是否需要提升；稍暗版用于比较私密感。三张变体采用同图编辑生成，构图接近，但细微纹理、云层和局部色调会漂移，不能当成严格只改一项数值的渲染 A/B。

## 验看与未完成项

`evidence/*-browser.png` 是四版本在实际 Chrome 中的无 UI 展示；`browser-check.json` 记录加载结果、原图和视口尺寸。只检查图片展示，不添加性能基准、动态效果或互动测试。

本轮**没有制作深度图、语义分层、猫独立动画、热点、音乐接入或 Scene 02 产品切换**；这些应在静态构图认可之后再推进。

美术仍需人工确认：是否愿意长期当壁纸、拿铁侧背花纹是否足够像本猫、窗台与坐垫的生活尺度、窗外清晰版是否抢主体。受侧背姿态与小尺寸限制，Hero 内绿眼及白爪不是高可读焦点；局部稿用于看侧脸和露出的白爪，仍不能宣称各角度身份纹理已完全锁定。局部稿是单独生成，不是 Hero 内已有高分辨率细节的像素放大。

原生更高分辨率母图、逐物体分层及严格变体像素一致性均未完成。这次不把技术扩展当静态视觉已经通过的证据。
