# 猫状态与声音接入

## 视觉状态

| 状态 | 触发 | 可见行为 | 退出 |
| --- | --- | --- | --- |
| observing | 首次、反应结束 | 趴着观察，轻呼吸、眨眼、偶尔耳动 | 点击或静置 |
| attentive | 点击猫 | 绘制的抬头姿态，缓动视线 | 7 秒后观察 |
| purring | 轻挠下巴 / 下巴按住 >0.45 秒 | 闭眼、微呼吸 | 7 秒后观察 |
| watching | 看看树枝 | 抬头、轻微向左看 | 6 秒后观察 |
| sleeping | 陪它休息 / 非交互静置 >38 秒 | 使用闭眼姿态 | 25 / 28 秒后观察 |

闭眼姿态本身是抬下巴的满足表情，休息沿用此图，尚没有单独的蜷身熟睡画。局部变形极小，适应画面里的猫尺度；呼吸不是整个角色上下漂浮。没有自动寻路、全身走路或大幅追随鼠标。

两处落点的 UV 为 `[0.69,0.24]`、`[0.79,0.215]`（从下往上），位于店旁干燥台阶；每次重新载入交替。猫、阴影和鼠标命中区域共享同一构图换算，脚部始终固定在落点。交互后仅沿用街景轻推近，不将猫放大成前景头像。

状态仅使用自己的版本键；遇到损坏或未来版本数据时不覆盖原记录。已有故事只保留页面会话状态，声音继续使用原键。减少动态与视觉暂停会冻结局部生命动画；用户仍可选择姿态，字幕也仍可操作。

## 复用 Sol Audio V1

来源：`nihongo-living-scene-audio-v1-20260906` 的 `873d2bdd6aef6903e4f9092e0b462090c361c98d`，只提取 `src/audio.js` 和原声音说明。原说明 [AUDIO_SYSTEM_V1.md](../audio/AUDIO_SYSTEM_V1.md) 保留为历史设计，以下是当前代码的差异。

保留原有缓慢和弦、稀疏音符、雨后空气、偶发滴水、暖店内声部，以及用户主动开启的方式。没有复制音频分支的旧页面、旧母图或 V2 入口。

- 新增 cat 总线：70–420 Hz 过滤噪声，25 Hz 轻脉冲，作为合成呼噜质感；只有 purring 状态淡入。不是用户猫的真实录音。
- 抬头 / 看树枝附带很轻的短促布料或爪部摩擦质感，4 秒限频；没有无缘由的项圈铃声或重复喵叫。
- 抚摸时 music 增益目标由常态 `.105` 降至 `.048`，休息 `.075`，一般字幕 `.074`；接近时 ambience `.062`。这些是混音参数，不是感知响度或耳机音量保证。
- 店内声部仅随店铺或灯笼热点升起，不再对所有环境热点视作进店。
- 去掉悬停敲铃；保留原 Audio V1 的进入、退出和开启声音提示。
- 混响发送改到 music / sfx 总线之后，确保音乐降低时湿声也一起降低。
- 隐藏页面会暂停 AudioContext 并停止事件排程；回来后重新排程，避免后台累积滴水或音符。

声音默认关闭；记得用户偏好也仍需当前页面主动点击。没有请求麦克风、读取系统音频、调用付费声音服务或加载第三方歌曲。

验收记录实际 AudioContext、状态混音、非静音输出和数值峰值。录屏配的是浏览器实时输出；最终音色自然度、呼噜辨识度、相对音乐的舒适程度仍需 Sol 听审。当前是程序合成的第一版声音整合，不是最终录音制作。
