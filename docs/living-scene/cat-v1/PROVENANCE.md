# Cat V1 素材来源与使用记录

| 素材 | 来源 | 使用范围与记录 |
| --- | --- | --- |
| 拿铁参考照片 | 用户在本任务提供的 8 张照片 | 为本项目角色设计提供身份、花纹与姿态参考；未视为开放许可素材。原始照片留在用户本机，不提交仓库 |
| 三张猫绘画 | 本轮用户已授权的 Codex 内置图像生成，3 次调用 | 项目生成素材；保存完整提示词和未经处理输出。没有擅自赋予 CC0、MIT 等第三方开放许可证 |
| 猫 RGBA / WebP / 蒙版 | 上述三张生成图派生 | 技术去底与边缘处理，沿用源素材用途；处理过程和限制均保留 |
| 背景街景 | V3 已交付的本项目生成及分区重绘素材 | 本轮直接复用；见 V3 交付及原有来源记录 |
| 音乐、环境音 | Sol Audio V1 的项目内 Web Audio 合成代码 | 同仓库分支复用，来源 commit `873d2bdd6aef6903e4f9092e0b462090c361c98d`；无第三方音乐录音 |
| 呼噜与轻摩擦音 | 本轮 Web Audio 程序合成 | 无猫录音、采样库、下载歌曲或付费生成服务 |
| Noto Sans JP | 既有 OFL 字体 | 沿用已有许可文件，仅对子集补入猫与声音界面字符 |

运行依赖 Three.js / postprocessing / three.quarks 的版本和许可沿用既有 Living Scene 记录，本轮没有新增运行依赖。离线去底工具、浏览器和编码工具不打包进入产品。

参考照片的哈希位于 `art-source/living-scene/cat-v1/image-inspection.json`；该文件记录实际用于身份评估的参考子集，不声称每张照片都逐张输入生成器。生成提示词注明输入角色与风格参考的用途。可编辑原图及 alpha 蒙版不包含用户家中背景或可读的项圈号码。

视觉限制：生成工具三次都返回 RGB，前两张背景为烘焙棋盘格、后一张为蓝灰色。透明成品来自后续技术处理；白胸白爪未简单按白色键删除。细胡须和亚像素毛发可能损失，三姿态身体细节并非完全逐像素一致。
