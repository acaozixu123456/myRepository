# Cat Companion V1 · 軒下の、ラテ

独立审核分支：`nihongo-living-scene-cat-v1-local-20260906`。基于 V3 `6da3fe64443121b2edaf62a5789acb83c25c85ec`；接入 Sol 声音分支 `873d2bdd6aef6903e4f9092e0b462090c361c98d` 的声音模块，未整分支合并，以免覆盖 V3 主图与对话。未部署、未合并生产分支。

## 打开与体验

- 本机构建预览：<http://127.0.0.1:8774/>；开发预览：<http://127.0.0.1:8773/>。
- 屋檐下的小猫是用户照片中的猫的风格化重绘。名称暂按照片文件夹采用「拿铁 / ラテ」。
- 悬停：轻微耳部与视线反应。点击：抬头、镜头轻推，出现一句日语。
- 轻挠下巴：闭眼、合成呼噜声，音乐缓缓降低。也可直接在下巴区域按住约半秒。
- 看看树枝：朝左侧树枝看；陪它休息：安静闭眼。无人互动一段时间后也会自行休息。
- 解释按需展开；Escape /「回到街景」退出。原有五处日语互动仍可使用，店主初见中增加一句介绍拿铁。
- 声音在屏幕边缘控件中主动开启，首次和刷新后均不自动播放。视觉暂停与声音开关分开。

用户指出初版猫比例过大，已将绘制宽度从画面源宽度的 11.5% 先调到 7.5%，再按第二次反馈调到 **4.5%**（第二次缩小 40%，约为最初的 39%），同步缩小阴影与命中区域。脚部落点保持不变。最终证据使用调整后的尺度；早期大猫截图不作为交付证据。

## 可编辑素材与实现

- `art-source/living-scene/cat-v1/raw/`：三张未经处理的内置生成输出，均为 **1254×1254 RGB**。
- `art-source/living-scene/cat-v1/latte-*-rgba.png`、`matte-*.png`：独立 RGBA 图与灰度蒙版，可在绘画软件中继续修边。
- `generation-provenance.json`、`image-inspection.json`：确切生成提示词、原始文件尺寸、哈希、参考照片指纹。
- `animation-anchors.json`：人工观察的眼、耳、头、爪、尾部位置；不是骨骼绑定或精细分割蒙版。
- `prototypes/living-scene/public/cat/`：三张带真实 alpha 的无损 WebP。
- `src/cat.js` / `cat.frag.glsl`：姿态过渡、局部微动、接触阴影、交互与有限记忆。
- `src/audio.js`：复用 Sol 的声音总线，新增猫声与场景联动。详细差异见 [声音与状态说明](STATE_AND_AUDIO.md)。
- `tools/prepare_cat.py`：生成图技术去底；`tools/verify-cat.mjs`：本原型浏览器验收和录制；`tools/encode_capture.py`：实际帧与同次音轨编码。

原始生成没有成功输出透明背景：前两张是画在 RGB 中的棋盘格，第三张是蓝灰底。运行时使用外连背景识别、GrabCut 和轻微边缘羽化后的真正 alpha；闭眼图的冷色颈部另加保护区域。没有抠取真实猫照片贴进街景，也没有将技术去底称作逐根毛发精修。

## 完成边界

P0 已形成可操作的浏览器候选：三张绘制姿态，轻呼吸、眨眼、耳尾微动、视线转向、抬头、抚摸、声音联动和轻日语。它是 **2.5D 姿态图与局部形变**，不是完整骨骼角色；三姿态的身体花纹略有生成漂移，过渡时仍可精修。

P1 只实现了轻量记忆和两处预定落点：刷新重访交替出现，抚摸次数保存在独立键 `livingScene.cat.latte.v1`，再次靠近有熟悉的招呼。**尚未实现自然走动、两处之间连续移动或自由路径探索**，没有用瞬移冒充行走。店主介绍与猫相关短句已接入。

尚待 Sol / 用户审阅：猫的肖似程度、表情与身体花纹一致性、毛边与胡须、合成呼噜的听感和最终混音。没有使用拿铁真实叫声或录音，没有日语配音。没有声称已进行人工耳机听审或最终母带处理。

雨后主图继续使用 V3 的 3039×1710 分区重绘合成候选，既有约 4% 补底和接缝限制见 [V3 清单](../v3/DELIVERY.md)，本轮没有重新宣称原生 4K。窗边黄昏、深夜书桌、沙发午睡等新场景留待此版通过后推进。

仅修改 Living Scene 原型、对应美术源与证据文档。生产入口、旧 Babylon、NHK、根依赖和后端均未改；没有运行 NHK 回归。来源与使用范围见 [素材记录](PROVENANCE.md)。
