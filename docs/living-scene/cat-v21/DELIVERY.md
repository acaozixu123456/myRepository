## 这轮实际修改

- 起身约 1.35 秒：原趴姿 → 前腿伸出 → 屈肘抬胸 → 后腿支撑 → 转向站立 → 侧向站稳，然后才沿台阶移动。左右各六个槽位，其中十个新绘姿态、两个复用原趴姿，未把右向简单镜像。
- 到达后约 1.5 秒倒序收腿回趴姿。起身与落座期间不推进位置；现有三处干燥锚点与稀疏行动节奏保留。
- 动作期间每一刻只采样**一个姿态**，取消趴/走全身交叉透明叠加，也取消两张走路轮廓的全身交叉混合。不是延长原 0.65 秒淡化。
- 鼠标靠近或打开猫交互时，当前帧和当前落点一起保持，离开后继续原路。不会在半途突然溶成另一只趴着的猫。
- 暂停、减少动态和后台行为沿用原规则；爪步只在实际行走阶段发出。声音架构、音乐、呼噜让位和五处原有日语热点继续复用。

## 尺度与美术处理

默认趴姿资产及 **0.045 名义源图宽度保持不变**，首/末动作帧直接复用原趴姿以避免落座改变默认大小。上轮行走帧把长尾和全身都压进相同宽度，头胸明显小了一圈；本轮采用有更多透明余量的 640 画布，以固定像素密度容纳展开的腿尾。**行走轮廓因此比 V2 行走更长，不代表所有姿态的外接框都固定为 4.5%。** 没有对每个动作帧单独按外接框拉大缩小，也没有运行时整体缩放脉冲。默认全屏构图需与走动态一起审核。

新图集的绘画更偏成年猫，保留绿眼、额头 M、白下巴/胸/爪、细棕项圈。原始图、透明 PNG、WebP、裁切注册记录、准确提示词及来源记录都交付。细花纹、脸宽与部分头部体积仍有生成漂移，未宣称“角色已完全锁定”。

## 验证与边界

构建通过；实际 Chrome 浏览器 **23 项检查全部通过**，加载和控制台错误为零。双向离线动作检查另证实六个起身/六个收腿帧、落脚固定、路径连续、暂停与注意力中断保持姿态。实际网页记录了自然 1→2 移动，约 **30.3 秒** 同次画面与音轨。录制等待产品自然出发，不缩短等待、不推进测试时钟、不强制产品锚点。视频 15 fps 是录制编码规格，不是网页帧率。本轮不做性能对照，构建已有体积提示不作为本轮优化任务。

仍需 Sol 看动作节奏与用户看拿铁肖似度：六帧过渡会有逐帧感，倒序起身并不等于单独绘制的完整落座表演；转身中间角度仍有限，花纹、毛边、脸型还有精修余地。移动中抚摸会暂停当前动作并播放现有声音/字幕反馈，侧面行走帧没有另绘眯眼表情。主观呼噜/环境/音乐最终听感仍待耳机听审。

本轮没有新场景、行为系统、3D 寻路、声音框架、NHK 修改或回归。原 V3 主图的分区拼接限制沿用。V2.1 通过后再考虑窗边黄昏，当前未擅自推进下一场景。
