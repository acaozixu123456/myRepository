# Cat V2.1 · 素材来源

- 新动作图集：本任务授权的 Codex 内置图像生成。两次调用，第二次纠正半起身不足；最终原始输出为 **1536×1024 RGB**，完整保留于 `art-source/living-scene/cat-v21/transition-atlas-raw.png`。第一版被淘汰，提示词及淘汰原因仍记录。
- 输入仅为已交付的 Cat V2 角色参考、休息图集、行走图集，以及第一轮生成候选；本轮没有再次上传用户私人照片。身份标准继续使用 `../cat-v2/identity-spec.json`，名字已获用户确认。
- 原图请求透明背景，实际返回烘焙棋盘格。运行 alpha 是外连背景识别、GrabCut 与轻微边缘软化的技术派生，不能称为工具原生透明图。未购买素材、未使用外部付费 API。
- 左右各六个过渡槽位：第一个都是 V2 已接受的同一趴姿，其余十个是新画姿态；右向开始姿势没有使用镜像。趴下倒序复用这些姿态，**没有另外绘制十二帧趴下动画**。
- 行走八帧来源为 Cat V2，校准到新的动作画布；头胸体积比原 V2 行走有所恢复，未凭空生成走路新细节。
- 生成素材沿用本项目用途，不擅自声明为 CC0/MIT；运行库、字体、背景、声音许可沿用 [Cat V1 来源记录](../cat-v1/PROVENANCE.md) 及 V3 原有记录。新增的只是项目制作脚本和角色序列，没有第三方素材包。
- 640×640 RGBA PNG/WebP 是统一可编辑画布，部分像素经过重采样，不是“原生 640 像素角色细节”。原始裁区、统一缩放、落点偏移、哈希详见 `atlas-manifest.json`、`source-inventory.json`。
- 另一侧花纹仍是参考表约束下的作者近似；生成姿态之间细小条纹及脸宽并未逐像素锁定。不要把此版当近景角色定稿。
