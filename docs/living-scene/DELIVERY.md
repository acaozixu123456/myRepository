## 制作与技术边界

1. 内置图像生成一次完成原创主视觉；用户明确授权，未调用其他付费服务。
2. 官方 Depth Anything V2 Small 本机 CPU 推理；原始深度保留，可复现脚本带模型参数、权重哈希与代码版本。
3. 枫叶误判做颜色/空间约束修正。远中近以羽化相对深度分区，三张蒙版相加为 255。
4. 运行时连续深度重投影，上限 X 0.006 / Y 0.003 UV，3.5% 预留画面边缘。局部风动幅度小于原图 1 px。
5. 画面像素预算约 207 万，DPR 最高 1.5，超出预算再自动降低；高密度设备避免浪费算力放大原图。
6. 本轮只新增三个独立目录，没有更改主游戏、NHK、根配置、后台或用户数据；未运行 NHK 回归，没有部署、合并或生产分支修改。

## 未完成项与建议

- **尚需 Sol 视觉验收。** 原图不是原生 4K；大屏细节应先由美术评估，再决定是否重新制作更高分辨率主图。
- 深度分区是可编辑工作层，尚非逐物体精修的语义抠图。没有重建叶片和房屋背后的隐藏背景。当前微视差可用，不能直接增大到明显横移或绕行；下一步优先精修树叶边缘、拆分灯笼/布帘与背景补绘。
- 风与光束为局部图像动画，落叶和尘埃为小型粒子；没有完整体积光、流体或三维遮挡模拟。
- 仅一张场景、一句文本；没有旁白/语音、其他街区、自由行走、复杂学习页和后端。本轮刻意集中在画面与少量交互。
- GaussianSplats3D、Spark、DepthFlow 仅完成官方资料与许可证研究，未宣称经过本机场景性能验证。
- 已验证本机 Chrome / AMD；Safari、Windows GPU、真实手机和长期热稳定性尚未验证。手机仅做窄屏布局回退，尚无专门竖屏构图。
- 录屏按捕获时间戳编码为 15 fps，不能用视频帧率代表网页 FPS。性能详见 `evidence/browser-report.json` 与 `PERFORMANCE.md`。
- 构建成功，但单 JS 包约 739 KB / gzip 185 KB，保留 Vite 大包提示；后续若增加多个场景再按需要拆包。
