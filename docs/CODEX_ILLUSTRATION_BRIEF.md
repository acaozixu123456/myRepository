# 立绘外包说明（给 Codex 的长期工作单）

你负责**画**《猫国志》全部 41 只猫猫的 AI 立绘；Claude 负责**审核、入库、接入游戏**。
这是一份可持续多轮交互的工作单：每一轮只做一件事，等审核意见回来再继续，不要一次性乱画一大批。

## 0. 先读这些
- `docs/ART_PROMPTS.md`：全局风格 + 每只猫的提示词（已锁定毛色、服装、武器、气质）。
- `assets/heroes/ref/<id>.jpg`：每只猫的参考图（现有造型渲染，**只用来锁定配色、服装、武器类型、五官特征，不要照抄它的画风和姿势**）。
- `docs/ILLUST_PROGRESS.md`：进度表。每一轮结束都要更新。
- `AGENTS.md`：分支 / PR 规则、专有名词、文案红线（没有血腥）。

## 1. 画什么（硬性规格）
- **一只猫一张图**：拟人站立的猫猫，全身，正面偏 3/4 角度，**动态姿势**，脸朝镜头。2.5 头身，二次元手游 Q 版立绘，厚涂 + 干净描边 + 柔和赛璐璐阴影。
- **手必须画对**：完整的猫爪手（拇指、指节、肉垫），握武器姿势自然；手臂从肩膀自然长出，有袖子，不能像“拼上去的”。这是上一版程序化造型被打回的主要原因，审核会重点看。
- **武器入画**：按提示词里的武器，贴着身体侧面，不遮脸、不穿模。
- **帅或可爱要有一个主打**：男将偏帅（眼神、站姿），小只 / 医者 / 谋士偏可爱，但都要是同一个画风体系。
- 背景：**透明 PNG**（拿不到透明就纯白底，我会抠）；脚下一小块柔和投影可保留。
- 尺寸：竖版，建议 1024×1536 以上，人物上下留 4% 边距，不要被裁切。
- 禁止：写实毛发、血腥、水印 / 文字、真人五官和皮肤、多余的手指或第三只手、衣服配色偏离参考图。
- 一致性：同一阵营的服装主色、点缀色相同（见提示词里的色值）；同一画风、同一光源（左上）、同一描边粗细。

## 2. 工作流（每一轮）
1. 从 `ILLUST_PROGRESS.md` 里取**状态为“返修”的优先，否则取下一只“待画”**（顺序：SP → UR → SSR → SR，同级按表中顺序）。
2. 用该猫的提示词 + 参考图出图；先出 2~3 个候选，自己先按第 4 节的清单自查，挑最好的 1 张。
3. 把成品放到 `assets/heroes/illust/<id>.png`（透明 PNG），**只改这一个图片文件 + `docs/ILLUST_PROGRESS.md` 里该行**；状态改为 `待审`，轮次 +1。
4. 开 PR（base 为主分支 `claude/awesome-babbage-ygba4h`，分支名 `codex/illust-<id>`，一猫一 PR；或在 Claude 同意后 3~5 只一批）。**PR 描述里贴出图片**，并写：用了哪条提示词、和参考图相比有意改动的地方、你自己觉得最不满意的一处。
5. 等 Claude 审核。审核结论只有三种：
   - **通过**：Claude 会跑 `python3 tools/sync-illust.py` 入库并合并，你把状态改成 `通过`，再取下一只。
   - **返修**：意见会列成编号清单（如“① 右手握法像捏着勺子；② 披风颜色偏紫”）。你**只改被点名的问题**，其余保持不变，轮次 +1，更新同一个 PR。
   - **换思路**：连续 3 轮同一问题没解决，Claude 会给出新的提示词或参考，按新的来。
6. 每只猫最多 4 轮；第 4 轮仍未通过，在进度表备注卡点，跳到下一只，不要卡住整个队列。

## 3. 风格锚点（先做这一只，定调）
**第一只必须是曹喵德（`wei_caomiaode`）**。它通过之前，不要画别的猫。通过后，它就是整个项目的“风格锚点”：后面每只猫生成时都把它的成品图也作为风格参考，保持线条、阴影、头身比一致。

## 4. 自查清单（提交前逐条过）
- [ ] 毛色、眼色、服装主色 / 点缀色与提示词、参考图一致
- [ ] 手：五指（或拇指 + 四趾）清楚，有肉垫，握持自然；双手数量正确
- [ ] 手臂与肩膀衔接自然，没有断层、没有“贴上去”的感觉
- [ ] 头身比约 2.5，头占比大、脸可爱或帅气，眼睛有高光，五官不歪
- [ ] 武器类型正确，不遮脸，不穿过身体
- [ ] 全身完整在画面内，透明背景，边缘没有白边 / 杂色
- [ ] 没有文字、水印、多余肢体；风格与曹喵德一致（定调后）

## 5. 不要做的事
- 不要改 `src/**`、`tools/**`、`tests/**`、`assets/heroes/ref/**`、`AGENTS.md`；只动 `assets/heroes/illust/` 和 `docs/ILLUST_PROGRESS.md`。
- 不要一次性生成 41 张再一起提交；不要为了“看起来统一”重画已经通过的猫。
- 拿不准的地方（比如某只猫的武器怎么握）写在 PR 里问，不要硬猜。

## 6. 审核方（Claude）会看什么
手和手臂 > 颜色和服装是否对得上设定 > 头身比与可爱 / 帅气 > 和曹喵德风格是否一致 > 抠图干净度。通过标准是“放进游戏卡牌、详情页、抽卡、绝技插画都不违和”。
