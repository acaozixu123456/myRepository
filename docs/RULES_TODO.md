# 关卡规则（Issue #32）

48 条关卡规则**全部已落地**为可执行的 `ruleFx`（`src/content/campaign.ts`，原语见 `src/engine/types.ts` 的 `RuleFx` / `RuleAct`）。

最后六条（2-9、2-24、3-24、5-3、5-24、6-24）原设计依赖“首次控制命中率”“护盾多持续一回合”“受击前闪避”“幻象消耗”这类很细的事件；为了让文案与实际效果完全一致，我把它们改写成引擎能准确表达的版本（预告 / 命中 / 闪避 / 火焰增伤），并同步了文案。

引擎当前支持：开场 / 每 N 回合 / 指定回合的状态，开场护体毛与元气，伤害 / 受伤 / 治疗倍率（可按职业、阵营、前后排、元素、护盾 / 状态条件、前 N 回合筛选），命中 / 闪避 / 暴击加成，首次治疗 / 首次普攻，每轮最低元气，绝技预告（`telegraph`），以及事件规则 `on`（普攻 / 命中 / 治疗 / 净化 / 护盾到期 / 护盾击破 / 暴击 / 受击 / 状态施加；可限定英雄、状态、第 N 次、最多次数、每回合一次、生命低于某比例）。
