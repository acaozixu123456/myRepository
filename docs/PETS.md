# 宠物系统

真正的小猫宠物（`src/data/pets.ts`，12 只：R 3 / SR 5 / SSR 4），头大身小、没有衣服，只有颈圈 / 披风 / 小冠这类配饰。

| 项 | 规则 |
| --- | --- |
| 获得 | 宠物蛋：每日首次快速探索、小游戏三星（每天最多 3 颗）、商店 200 金铃铛；孵蛋 R 70% / SR 25% / SSR 5%，20 颗保底 SSR；重复 → 碎片（R8 / SR14 / SSR30） |
| 养成 | 等级上限 10+4×星（最高 30），升级吃小鱼干 400×Lv；升星 5 档，碎片 15 / 40 / 75 / 120 |
| 加成 | 出战宠物全队 +1.5%+0.12%×(Lv-1)+0.8%×(星-1) 的生命 / 攻击 / 防御（<10%），同时进显示战力和实战属性 |
| 技能 | 战斗第 2、5、8… 回合开场出手一次（`BattleConfig.pet`，事件 `{t:'pet'}`），威力 = 0.45 × (1+2.5%×(Lv-1)) × (1+8%×(星-1))；以我方最强攻击者的面板结算 |
| 表现 | 小猫从队伍后面蹦出来，脚下爪印符阵 + 技能特效（`src/fx/pets.ts`：heal / shield / buff / energy / strike / bolt / fire / debuff），放完淡出；探索里跟在队尾一蹦一蹦 |

代码：规则 `src/game/pets.ts`（测试 `tests/pets.test.ts`），界面 `src/app/screens/pets.ts`（主城快捷入口「宠物」）。
新增宠物只要往 `PETS` 里加一条（外观 + 技能），外观自动进 `lookOf`。

## 平衡抽样（2026-10-12）
用「按关卡节奏养成、无装备」的玩家打首领关（1-24 / 5-24，各 60 次）：未带宠物 55% / 43% 通关；全队 +1 / +2 / +3 级分别约 58~52% / 72~53% / 80~75%。
原版宠物（技能系数 1.0）Lv5 ★1 就能把通关率推到 90%+（≈ 全队 +3 级以上），其中加成约 +6~14 个点、技能约 +30 个点。现把技能系数乘 0.45（`PET_SKILL_K`）、基础加成降到 1.5%，Lv5 宠物约等于全队 +2 级（73% / 75%）。
其余节奏关卡（普通关）本来就 100%，不受影响；2-24~4-24 的首领对「无装备节奏玩家」本来就是 0%（需要装备 / 养成补足），宠物也不改变这一点。
