当前产品已是 NHK 主线，不再按旧的世界剧情/七玩法架构设计。已有 MOJi 导入、跨日文章库、重点句 AI 分析、词汇/语法手动收藏、分段语音、静音输入、录音反馈及间隔复习。此前的缺陷不是“没有内容”，而是逐层功能全部挤在一次学习中。

原始问题：整篇/3句/复述/观点等操作堆叠；全文列表和讲解密集；收藏复习一开始就展示释义；连续天数容易被当成任务债；多层样式叠加与固定窄屏。线上此前独立 GET 验证 HTTP 200，不能把 Vercel 连接列不出项目误判为线上故障。

## 产品原则

保留“每篇彻底理解”的长期目标，但不要求当天一口气做完。学习单位从“今天必须完成一篇”变成“先读懂一句、回想一次”；停止是正常选择，不扣分，不清空累计。减少开始前的选择，不把简单模式再做成三四张选择卡。

理解、当下回想、延迟回想、迁移是不同证据。点击完成或主观“想起来了”不代表长期掌握。微练习单独记录，绝不因此设置原 article.completedAt。原 completedAt 的 UI 改为完成过输出练习，而不是“已学完”。

## 本次实现

- 全新暖白/浅鼠尾草绿/浅杏色视觉；系统字体、留白、深色正文；桌面双栏，手机单栏。主导航仅“今日 / 文章 / 复习”。所有当前页面共享一个 NHK stylesheet，旧 CSS 不再加载。
- 首页突出一个继续入口，优先恢复上次文章与句子，不因午夜强推新文章。空状态只引导导入第一篇。足迹保留真实活动日期，不使用连续打卡清零。
- 导入即保存原文，默认选一个重点句；全文和手动最多3句选择折叠。已开始读的句子不会被晚到的 AI 响应擅自更换。
- 精读默认只显示一句、含义、简短结构；语法、词汇、迁移和播放器按需展开；完整解释、例句、手动收藏不删除。
- 一句闭环：阅读 → 合上提示 → 在心里想/可选输入 → 揭晓原句 → 自评。回想时原句卸载，不仅视觉隐藏；录音不是必经步骤。小结优先“今天到这里”，继续/输出是次级可选。
- 收藏复习固定一小组最多3个；释义、来源句和例句在揭晓后才显示，揭晓前不能评级；防重复评级；队列只是展示限量，未展示记录与到期时间不被删除/篡改。
- 复习与浏览收藏分离，保留搜索、类型筛选、来源回跳和有确认的移除。
- 输出练习保留，静音输入可完成，观点可选。底层语音服务不更换。
- 明示当前浏览器存储边界；写入失败不再静默成功/崩溃，提供警告及备份；备份 JSON 包含新的 gentleProgress。

## 研究依据（证据与设计假设分开）

1. Alamer et al., 2025, *Self-Determination Theory and Language Learning: A Multilevel Meta-Analysis*, Educational Psychology Review 37:59, DOI 10.1007/s10648-025-10038-y. 自主性动机与成绩、较低焦虑相关。元分析以关联为主，不是本产品干预有效的证明。支持保留选择权与停止权，不据此声称所有奖励都有害。
   https://link.springer.com/article/10.1007/s10648-025-10038-y
2. Kim & Webb, 2022, *The Effects of Spaced Practice on Second Language Learning: A Meta-Analysis*, DOI 10.1111/lang.12479. 支持跨时间分散练习；立即测验与延迟测验不同，固定与递增间隔未显示普遍优劣。保留现有间隔安排，但不宣传“1/3/7天对所有人最优”。
   https://onlinelibrary.wiley.com/doi/10.1111/lang.12479
3. Karpicke & Roediger, 2008, *The Critical Importance of Retrieval for Learning*, Science 319, 966–968, DOI 10.1126/science.1152408. 词汇实验支持主动检索对延迟保持的价值。应用为先尝试回想再反馈，而不是把熟悉感当掌握；不能保证单次自评等价客观掌握。
   https://doi.org/10.1126/science.1152408
4. Lally et al., 2010, *How are habits formed: Modelling habit formation in the real world*, DOI 10.1002/ejsp.674. 日常行为研究支持稳定情境中的重复，个体形成过程差异大；不是日语 App 实验。不宣称21天规律。设计外推：接在用户现有的 MOJi 阅读之后，缺席后容易回来。
   https://onlinelibrary.wiley.com/doi/10.1002/ejsp.674
5. Rey et al., 2019, *A Meta-analysis of the Segmenting Effect*, DOI 10.1007/s10648-018-9456-4. 为分段与学习者控制提供依据，不意味着越碎越好。应用为句子单位但始终保留原文、上下文与迁移入口。
   https://doi.org/10.1007/s10648-018-9456-4
6. WCAG 2.2：正文对比度、键盘焦点与可触控区域。实现选择44 CSS px触控目标（高于AA最低24px）；自动审计不等于全站或真机完整无障碍认证。
   https://www.w3.org/TR/WCAG22/

“一次1句”“一组3个”是本版可调整的产品假设，不是神奇时长或脑科学定律。不使用多巴胺破解、无意识吸收、零努力速成等承诺。低阻力意味着减少无关决策、羞耻与界面负担，不是取消听辨、回想和表达本身的必要努力。

## 后续效果验证：建议观察两周，而非立即宣传有效

本次没有向第三方新增行为分析或发送用户学习内容。已有本地进度可以支持观察，但以下实验与指标尚未实现自动采集：

- 接受度：开始前主观抗拒0–5、从打开到开始阅读的耗时、主动返回与中途放下原因。
- 坚持度：有自主学习行为的天数；缺席后恢复，而不是最长连续天数或页面停留。
- 学习：当天不看原文的意思回想；次日/一周后无提示回想；把同一表达用于不同真实句子。自评与客观小题分开，不能只看点赞或勾选数。
- 负担：单组3个过重则减为1–2个，仍愿意继续则自选追加；不给全部积压套一个红色待完成数字。

在用户自身的 MOJi/NHK 流程中比较体验即可；只有一两位用户时不能将结果泛化为群体因果效应。下一优先级是可靠云端备份/恢复与更精准的理解反馈，不是再加关卡世界或强提醒。

## 测试范围与边界

本次在独立分支实现。构建、单元测试、合成 fixture 浏览器交互需通过后才能提交到生产分支。测试数据明确是合成文章，不是爬取的NHK正文或用户资料。浏览器 API 均 mock，验证导入/失败状态与交互，不等价真实 AI 输出质量、真实扬声器听感、iOS 真机录音权限或网络验证。
