怎么走

左下角的方向盘往哪推就往哪走，推得越远走得越快；屏幕其他地方拖动转镜头看风景（也可以换回“按住屏幕走”）。下面随时换成步行、骑马或者飞；点右上角的时辰可以快进到下一段，点「地图」看看去过哪儿、想去哪儿。
新的：野外多了四处营地，坐下就点起篝火，可以歇到清晨、正午、黄昏或者夜里；看到好看的点「拍照」，照片收进「手记」，每个地方第一张照片就是它的封面。
