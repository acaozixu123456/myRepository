# 战斗语言：状态效果与职业

## 状态效果

| 名称 | 类型 | 说明 | 备注 |
|---|---|---|---|
| 炸毛 | 增益 | 攻击力提高（常见 +20%~30%）。 | 可叠层，同名取最高。 |
| 团团 | 增益 | 蜷成毛团，防御力提高。 |  |
| 呼噜 | 增益 | 每回合开始回复一定比例的最大生命。 | 呼噜声越大，回得越多。 |
| 护体毛 | 增益 | 获得护盾，先于生命值承受伤害。 | 魏势力「铁壁」的主力。 |
| 猫步 | 增益 | 速度提高，更早出手。 |  |
| 九命 | 增益 | 受到致命伤害时免死一次，并保留少量生命。 | 每场战斗每只猫猫最多触发 1 次。 |
| 幻象 | 增益 | 留下幻象替身，闪避下一次受到的攻击。 |  |
| 挑衅 | 增益 | 嘲讽：敌方普攻只能选择自己。 |  |
| 抓痕 | 减益 | 流血：每回合受到持续伤害（按施加者攻击力计）。 | 蛮势力「图腾」的叠层来源。 |
| 灼烧 | 减益 | 火焰持续伤害，可叠层，叠层越高每次越痛。 | 对「淋湿」目标额外伤害；吴势力「赤壁」核心。 |
| 淋湿 | 减益 | 浑身湿透：防御降低，并更容易被火焰与符咒影响。 |  |
| 晕乎乎 | 减益 | 眩晕：无法行动。 | 被控制过的猫猫短暂免疫再次眩晕。 |
| 毛线缠 | 减益 | 被毛线缠住：无法释放绝技，只能普攻。 | 「封印」的猫式叫法。 |
| 受惊 | 减益 | 攻击力降低（常见 -20%~25%）。 |  |
| 猫薄荷醉 | 减益 | 醉倒：会攻击自己的队友，并更容易受伤。 |  |
| 符咒 | 减益 | 被贴符：受到的伤害提高，可叠 3 层。 | 仙势力「天机」核心。 |
| 铃铛标记 | 减益 | 被标记：受到的伤害提高 10%，并更容易被暴击。 |  |

## 职业

| 职业 | 站位 | 说明 | 基础生命 | 攻击 | 防御 | 速度 |
|---|---|---|---|---|---|---|
| 守护 | 前排 | 吸收伤害、嘲讽与护盾，队伍的“猫抓板”。 | 1200 | 95 | 80 | 90 |
| 先锋 | 前排 | 近身高爆发，擅长切入与追击。 | 900 | 130 | 55 | 105 |
| 神射 | 后排 | 远程物理输出，多段与暴击。 | 760 | 150 | 40 | 110 |
| 谋士 | 后排 | 法术群伤与控制，战场的指挥官。 | 720 | 145 | 38 | 100 |
| 医者 | 后排 | 治疗、净化与复活，队伍的“猫薄荷”。 | 800 | 90 | 50 | 100 |
| 刺客 | 后排 | 绕后飞刀，专杀后排脆皮。 | 700 | 150 | 38 | 125 |

稀有度系数：SR ×0.82，SSR ×1.0，UR ×1.2（速度系数更平缓）。
