# 3D 探索冒险模式（方向与架构）

## 方向
游戏从「纯挂机」转向 **3D 冒险卡牌手游**：玩家操控一队猫猫在赛博朋克风的 3D 微缩街区里走动、探索、遇敌开战、开宝箱、找 NPC；抽卡 / 阵容 / 技能 / 养成 / 活动 / 公会等原有玩法全部保留，挂机收益仍在（离线 / 主城）。

## 画风
- 主调：**雨夜 · 霓虹 · 湿漉漉的反光地面 · 密集的招牌与线缆 · 远处的巨型都市与全息广告**（参考用户给的两张图：等距微缩街角 + 暗调赛博朋克街景）。
- 猫猫是卡通渲染的 3D 小猫（`src/art3d`），场景是偏写实的暗调环境；两者靠光照（霓虹点光 + 冷色轮廓光）和泛光衔接，而不是强行同一材质风格。
- 第一版是程序化几何 + 程序化贴图；要接近参考图那种质感，需要「AI 绘制的贴图素材」（外墙脏污、招牌、广告牌、远景天际线）贴到程序化几何上，见 `docs/CODEX_WORLD_BRIEF.md`。

## 游戏循环（第一版）
- 街区北端有**关卡首领**（= 主线下一关）：打赢推进主线并拿首通奖励（含剧情）；已全通则可重复挑战。
- 街区里有 6 队**巡逻野怪**（= 当前已通的最高关）：靠近会追；打赢拿小鱼干 / 经验（每天 40 场有奖励），90 秒后刷新。
- 4 个**宝箱**（每天刷新一次）、1 位**向导 NPC**（嫦喵，给提示）。
- 输了：队伍回到出生点，野怪冷却。

## 路线图
1. ✅ 引擎 + 第一个街区 + 队伍操控 + 遭遇战 + 奖励
2. 画面提升：湿地面反射、远景都市 / 全息广告牌 / 飞行器、蒸汽与脏污、色彩分级、AI 贴图接入
3. 更多街区（对应章节主题：集市、赤壁、森林、雾岛、宫殿）+ 区域间传送门
4. 玩法扩展：任务 NPC 链、隐藏宝箱 / 采集点、精英怪、区域 Boss 机制、队伍技能在探索中的用法（猫爪印地图技能）
5. 战斗也搬进 3D 场景（现在是浮层里的 2D 背景 + 3D 猫）

## 性能预算（软件渲染下量的，真机待测）
- 绘制调用 ≈ 281（关阴影），开阴影 ≈ 695；三角面 ≈ 31 万。手段：静态景物合批（纯色材质统一成顶点色、同风格楼共用立面材质）、猫描边烘焙进顶点、飞行器 Instanced、蒸汽 Points、远处的猫隐藏。
- `WorldView` 有自适应画质：连续掉帧（平均 < 30fps）依次关雨 → 阴影 → 泛光 → 降分辨率。
- 新增道具请遵守 `docs/CODEX_WORLD_BRIEF.md` 的约束（缓存材质、≤40 网格），合批会替你处理其余。

## 已验证的流程（浏览器里自动化跑过）
遇野怪 → 战斗浮层 → 胜利奖励；碰首领 → 战斗 → 通关弹窗 → 主线推进 1-1 → 1-2；**战败**（1 级队伍打 4-21）→ 战败弹窗「战力 483，推荐 2,033」→ 无报错；乱点测试（含探索页）无报错。（软件渲染下一场战斗要几分钟，真机会快得多。）

## 操作
- 点地面 / 点实体：A* 寻路走过去；拖动旋转镜头，双指缩放。
- 左下虚拟摇杆、桌面 WASD / 方向键：相对镜头朝向直接移动，撞墙沿墙滑行（`Explorer.push`）。
- 遭遇战用圆形转场（`arenaFight` 的 banner 参数）；战斗背景是 `WorldView.backdrop()` 从街面高度拍的当前街景（隐藏小猫和头顶标签），战斗本身仍是 2D 浮层 + 3D 小猫离屏渲染。
- 嫦喵的每日委托（`src/game/explore.ts`）：击败 5 只野猫 / 打开 3 个宝箱 / 赢 1 场首领战，三项完成后找嫦喵领奖（小鱼干 + 经验 + 6 猫薄荷 + 40 金铃铛，每天一次，5 点刷新）；进度显示在探索界面左侧。
- 探索音效：雨声环境音、猫爪脚步、野怪发现警示音（`src/app/sfx.ts`，程序合成）。
- 猫薄荷丛：每个街区 3 丛（`DEFAULT_HERBS`，摆在马路上），走近采集，每天每丛一次，给 3~5 猫薄荷 + 少量小鱼干；不计入「打开 3 个宝箱」委托。
- 探索足迹（`TRAIL`）：击败野猫 / 开宝箱 / 采猫薄荷 / 赢首领战的长期累计目标，各 3~4 档，够数后在「足迹」弹窗手动领取（小鱼干 + 经验，高档带猫薄荷与金铃铛）；累计不受每日上限影响，隔天不清零。

## 性能预算（实测，软件渲染下数三角面，桌面带阴影）
- 3D 小猫是三角面大头（每只 3~4.5 万，约一半是描边外壳）。探索世界里的猫用 `detail.k = 0.6` 降细分（`art3d/toon.ts` 的 `detail`），战斗与立绘保持满细节；只有玩家队伍投射实时阴影，其他猫用脚下的假阴影；距队长 46 单位以外的实体不渲染；世界里的猫开启视锥裁剪（包围球放大 1.5 倍防误裁），距离 26 以外的实体猫不画描边外壳。
- 真实探索画面：2.41M → 0.77M 三角面、790 → 614 次绘制。手机上阴影默认关，实际负担更小。
- 视锥裁剪后：地图角落 70 万 → 21 万三角面，出生点 77 万 → 64 万。
- 远景天际线接入点（`backdrop.ts`）：assets/world/skyline* 一旦存在（Codex A07）就自动贴成外圈柱面；当前玩法镜头俯视街道，天际线只在低角度看远处时露出，真素材（A07 `skyline_catcity_01`）已接入并实测：游戏镜头压低看街时，外圈巨楼（高 30~140）几乎把天际线整个挡住，只在楼缝和楼顶上方露出，所以柱面加高到 200 让紫色天空接在楼顶之上。
- 自动探索（探索页「自动探索」开关）：先去最近的猫薄荷丛 / 宝箱，再找最近的野猫，每日野怪奖励拿满后只采集；首领、嫦喵不自动去，靠近首领（9 以内）的目标跳过以免误开首领战；摇杆 / 键盘接管、打输、没目标、离开探索页都会自动关闭。选目标的纯逻辑是 `pickAutoTarget`（有测试）。
- 调试页新增 `?focus=x,z`：镜头对准某个点看道具（注意别让镜头钻进楼里；十字路口两条马路是 |x|<4.5 和 |z|<4.5，人行道只在四个角上）。

## 场景玩法入口（POI）与小游戏
方向：每个场景有自己的玩法，不只是打架（赛博街区进店玩小游戏、沙漠卡丁车、海边钓鱼……）。做法：`LevelDef.pois` 里放玩法入口，走近触发 `hooks.poi`，世界暂停，app 层按 `game` 名打开对应小游戏界面，结束后世界继续（`Explorer.startPoi`，与遭遇战同一套暂停机制）。自动探索中路过不会触发。
- 钓鱼（赤壁港）：`game/fishing.ts`（规则，纯逻辑）+ `app/screens/fishing.ts`（界面）。抛竿 → 等咬钩 1.2~4 秒 → 0.9 秒窗口内提竿，350ms 内算「完美」（去掉杂物、优质以上权重 ×1.8）。7 种鱼（普通 / 优质 / 稀有 / 传说 + 杂物），每天 30 竿，奖励以**当前最高关的挂机奖励为基数**（和主线进度挂钩），鱼图鉴 6 种，累计钓鱼数进「足迹」3 档。
- 拉面屋台（霓虹夜市，喵喵拉面店门口）：`game/ramen.ts` + `app/screens/ramen.ts`。客人（夏侯墩、吕布丁、董桌……）点 3 样配料，8 秒内**按顺序**点（点错记失误），再在移动的标记进绿区时「起锅」。星级：做完 1 星、零失误 +1、起锅完美 +1、起锅失手最多 1 星、没做完 0 星。每天 12 碗，奖励以当前最高关挂机奖励为基数（×0 / 1.5 / 3 / 6），3 星带猫薄荷和金铃铛；累计碗数进「足迹」3 档。
- 纸箱寻猫（纸箱街，路口边的纸箱）：`game/boxcat.ts` + `app/screens/boxcat.ts`。猫躲进一个纸箱，箱子互换位置（第 1~5 轮：3→3→4→4→5 个箱子，交换次数和速度逐轮加码），猜猫在哪个。每猜对一轮可「收手领奖」或「继续挑战」；猜错只能拿走已赢档位的一半。奖励倍数 ×1.2 / 2.5 / 5 / 9 / 16，3 连起带猫薄荷、5 连带金铃铛；每天 6 局；找到的猫累计进「足迹」3 档。
- 采蘑菇（霓虹森林，蘑菇地）：`game/mushroom.ts` + `app/screens/mushroom.ts`。反应类：25 秒内 3×3 蘑菇地里蘑菇冒出来又缩回去（红香菇 +1、金蘑菇 +3、紫色毒蘑菇 −3），出场表由随机种子生成并有「同一格不重叠」「满分能拿满档、只点一半拿不满」的测试。分数线 10 / 20 / 30 对应 1 / 2 / 3 档，奖励 ×1.5 / 3.5 / 7，每天 6 局，采到的蘑菇数累计进「足迹」。
- 风铃节奏（云端雾岛，风铃架）：`game/windchime.ts` + `app/screens/windchime.ts`。节奏类：音符沿 3 条轨道（叮 / 咚 / 铃，也可按 A / S / D）落下，落到金线时点对应轨道；±80ms 完美、±170ms 好，更远算失误，离所有音符太远的空点不扣分。32 个音符、命中率 50% / 70% / 88% 对应 1 / 2 / 3 档，奖励 ×1.6 / 3.8 / 7.5，每天 6 局，命中数累计进「足迹」。
- 小游戏打开时：世界渲染停掉（画面定格）、HUD 藏起来（`.screen.mg`）。实测不这样做的话，HUD 的 `backdrop-filter` 模糊盖在定格的 WebGL 画面上每帧重新合成，软件渲染下计时器晚 0.2~1.5 秒，节奏类玩法几乎打不了；这样做之后计时器延迟是 0。探索时（世界在渲染）去掉模糊没有帧率差别，所以那边没动。
- 点灯（九重宫阙，宫灯阵）：`game/lanterns.ts` + `app/screens/lanterns.ts`。逻辑解谜：3×3 九盏宫灯，点一盏翻转它和上下左右，全部点亮过关。题目由「全亮」随机点几盏得到，保证有解（测试穷举验证 3×3 的 512 种灯阵全部有解）；最少步数由 512 种点法穷举。一局 3 道题一道比一道难，多点的步数总和 0 → 3 星、≤3 → 2 星、其余 1 星，奖励 ×1.5 / 3.5 / 7；每天 6 局；点亮的题数累计进「足迹」。至此六章每章都有自己的玩法：寻猫 / 拉面 / 钓鱼 / 采蘑菇 / 风铃节奏 / 点灯。
- 安全区：每个玩法入口周围 `SAFE_R = 8` 格是安全区（地上有一圈淡淡的边界）：野猫刷新点落在区里会被挪到区外（`relocateOutOfSafe`），追击和巡逻都进不来，队伍在区里时不会被开战。战斗和小游戏互不强绑定：想玩小游戏就走进圈里，想打架就走出圈。
- 新增小游戏的步骤：关卡里加 `pois`；`app/screens/` 写界面并导出 `open*(ctx, host): Promise<void>`；在 `explore.ts` 的 `onPoi` 里按 `game` 分发；规则写成 `game/` 下的纯函数并配测试。
- 新场景（沙漠、海边等）稍后新增，先在现有场景里验证这个模式。

## 踩过的坑
- `WorldView.start()` 第一帧 `dt` 可能是负数（rAF 帧时间戳早于 `start()` 里取的 `performance.now()`，主线程被建场景堵了几秒时），负 `dt` 会让所有冷却跳高 5 秒、角色倒退。已在 `engine.ts` 夹到 ≥ 0。

### 怎么加 / 改一个场景
1. **布局数据（纯数据）**写在 `src/world/themes/<name>.data.ts`，导出 `<name>Level(): LevelDef`，带 `theme`、`solids`（碰撞盒）、`enemySpots / chestSpots / herbSpots / pois / bossSpot / npcSpot / spawn`。**碰撞盒是布局的唯一数据源**：渲染与寻路都从它来。
2. **渲染**写在 `src/world/themes/<name>.ts`，导出 `build<Name>(L): Street`，在 `themes/index.ts` 里注册；收尾用 `finishTheme()`（合批 +（可选）倒影）。共用件：`themes/common.ts`（地基、地面、带状路、萤火虫、投影、光束）、`themes/arch.ts`（飞檐屋顶、殿堂、牌楼、灯笼、台阶、栏杆、宝塔）。
3. **氛围**在 `src/world/atmos.ts`：天空穹顶三色 + 太阳光盘 / 光 / 雾 / 曝光 / 泛光 / 调色 / 跟队暖光，`LevelDef.mood` 选一套。`LevelDef.weather: 'none'` 关雨。
4. **测试**：`tests/levels-reach.test.ts` 对每个关卡洪水填充：出生点必须走得到所有刷怪点 / 宝箱 / 猫薄荷 / 入口 / 首领 / 向导，且不压在碰撞盒里、安全区里没有野猫。改布局先跑它。

### 坑
- 走路高度固定 y = 0.32，不能有台阶 / 坡：任何落差（云岛边缘、水、溪流）都必须是碰撞盒。
- 寻路网格会把碰撞盒外扩 0.9：通道至少留 4.6 宽才有 2 格可走（桥洞、巷口）。
- 离镜头 6~16 米的静态景物会「抖动淡出」（`bake.ts` 的 `nearFade`），否则参天大树 / 高屋顶会糊住画面；带贴图的大件要自己套 `nearFade`。
- 切场景要释放几何体（`loadLevel` 里已做），材质和贴图是跨场景缓存的，不要释放。

## 探索玩法：视野 · 偷袭 · 探路技 · 隐藏宝箱（不再是单纯走路）

- **视野**：每只野怪 / 首领脚下有一片扇形视野（黄色，半角约 55°、9 米）。没发现你时原地左右张望、巡逻；队伍走进扇形（或贴脸 2 米内）就会被发现——头顶 ❗、原地盯你 0.7 秒（反应时间），然后变红开始追你（追击速度 3.7，队伍 8.2，跑开就能甩掉；离开 17 米或看不见 4 秒放弃）。首领只会盯着你，不追。进场景 / 被击退后有 4 秒宽限。
- **三种开战方式**：正面开战（点「战斗」，和以前一样）；**偷袭**——绕到背后 / 潜行中 / 敌人被撞晕时，按钮变成「🗡️ 偷袭」，开局我方元气 +70、奖励 ×1.5；**被抓住**——敌人追上你，对方开局元气 +70，我方 0。
- **探路技**（场景里左侧三个按钮，快捷键 Q / E / R，由队伍里的职业决定谁能放，没有就置灰并提示）：💨 **冲撞**（先锋 / 守护，冷却 9 秒）向前冲 7 米，撞晕沿途敌人 4 秒；🤫 **潜行**（刺客 / 神射，冷却 14 秒）8 秒内视野缩到 3.2 米、移动慢 38%，贴近可偷袭；👁️ **灵视**（谋士 / 医者，冷却 16 秒）6 秒内 26 米内的隐藏宝箱显形。**阵容搭配因此影响探索**。
- **隐藏宝箱**：每个场景 3 个，在地图的「死角」（周围碰撞盒最密的可走格，`levels.ts hiddenSpotsOf`，种子固定），走到 4 米内或用灵视才显形，奖励是普通宝箱的 2 倍以上并必有猫薄荷 / 金铃铛。
- 代码：`world/explore.ts`（视野 / 追击 / 技能），`game/explore.ts`（隐藏宝箱计划与奖励），`app/screens/explore.ts`（按钮 / 提示 / 偷袭奖励），`app/arenaFight.ts` 的 `ambush` 参数；测试 `tests/explore.test.ts`「隐藏宝箱」。
- **掩体**：每只野怪附近 5.5~9.5 米处一个（`levels.ts coverSpotsOf`，位置固定，可走、不挡路），按场景换皮——纸箱堆（街区）/ 货箱（夜市）/ 木桶（码头）/ 草丛（森林）/ 云团（云岛）/ 屏风（宫阙）。躲进圈里（半径 3 米，`Explorer.hiding`）敌人视野缩到潜行水平（3.2 米），并且从里面出手算偷袭，不用技能也能摸过去；潜行 + 掩体叠加没有额外效果。
- **传送门**：每个场景一对（`levels.ts portalSpotsOf`，开阔、相距 ≥ 18 米，位置固定），一道同色光柱 + 转动光环（颜色按场景：街区粉 / 夜市橙 / 码头青 / 森林紫 / 云岛浅蓝 / 宫阙金）。走进一个就出现在另一个（冷却 2.5 秒），所有正在追你的敌人跟丢。抄近路 + 脱身。`tools/explore-flow.mjs` 的 F 项验证传送。
- **场景机关**（`levels.ts zonesOf`，每处半径 3.2 米的彩色圆盘，位置固定）：云岛 = 🌬️ **风口**（顺风推一把，移动速度 ×1.5，箭头流动）；码头 = 🌊 **潮汐滩**（队伍 ×0.55，追你的敌人在滩里也 ×0.55，涟漪）；宫阙 = ✨ **琉璃滑地**（松手后还会顺着惯性滑约 1 秒）；街区 / 夜市 / 森林没有（它们有掩体和传送门）。进入时头顶提示一句。
