# 3D 探索冒险模式（方向与架构）

## 方向
游戏从「纯挂机」转向 **3D 冒险卡牌手游**：玩家操控一队猫猫在赛博朋克风的 3D 微缩街区里走动、探索、遇敌开战、开宝箱、找 NPC；抽卡 / 阵容 / 技能 / 养成 / 活动 / 公会等原有玩法全部保留，挂机收益仍在（离线 / 主城）。

## 画风
- 主调：**雨夜 · 霓虹 · 湿漉漉的反光地面 · 密集的招牌与线缆 · 远处的巨型都市与全息广告**（参考用户给的两张图：等距微缩街角 + 暗调赛博朋克街景）。
- 猫猫是卡通渲染的 3D 小猫（`src/art3d`），场景是偏写实的暗调环境；两者靠光照（霓虹点光 + 冷色轮廓光）和泛光衔接，而不是强行同一材质风格。
- 第一版是程序化几何 + 程序化贴图；要接近参考图那种质感，需要「AI 绘制的贴图素材」（外墙脏污、招牌、广告牌、远景天际线）贴到程序化几何上，见 `docs/CODEX_WORLD_BRIEF.md`。

## 架构
| 模块 | 职责 |
| --- | --- |
| `src/world/engine.ts` | `WorldView`：透视「微缩景观」相机、泛光、雾、雨、点击 / 拖动 / 捏合；画质档位 |
| `src/world/tex.ts` | 程序化贴图（窗户立面 + 亮灯窗、霓虹招牌、路面、地砖、光斑） |
| `src/world/kit.ts` | 场景部件（楼房、招牌、电线杆、电车、自动贩卖机、纸箱堆、招财猫…）；楼分「低层 / 高层」，高层挡住视线时折叠 |
| `src/world/props/` | 道具注册表（新增道具放这里，关卡按名字摆放） |
| `src/world/levels.ts` | **关卡数据**（纯数据）：楼、道具、灯、电线杆、拱门、灯笼串、光色、出生点 / 首领 / 野怪 / 宝箱 / NPC 位置；六章各一份（1 纸箱街、2 霓虹夜市、3 赤壁霓虹港（水面 / 集装箱 / 龙门吊 / 货轮）；4 霓虹森林（树屋 / 发光巨树 / 蘑菇）；5 云端雾岛（水晶簇 / 石灯笼 / 浮空岩）；6 九重宫阙（朱红柱 / 石猫守卫 / 午门拱））；`levelColliders()` 给寻路和测试 |
| `src/world/street.ts` | `buildStreet(level)`：把关卡数据搭成 3D（路、人行道、楼、道具、电线、倒影、外圈都市、蒸汽） |
| `src/world/backdrop.ts` / `steam.ts` | 外圈巨型都市 + 全息广告牌 + 飞行器（Instanced）；蒸汽（Points） |
| `src/world/bake.ts` | 静态合批（绘制调用从几百降到几十） |
| `src/world/explore.ts` | `Explorer`：队伍移动（A* 寻路、跟随队列）、野怪巡逻 / 追击、宝箱、NPC、遮挡楼折叠、触碰事件 |
| `src/game/explore.ts` | 规则（纯逻辑）：地图上放什么、奖励、每日上限；`tests/explore.test.ts` |
| `src/app/arenaFight.ts` | 遭遇战：全屏浮层里用现有战斗引擎 / 回放器打一场 |
| `src/app/screens/explore.ts` | 探索界面：HUD、进出场景、把遭遇战 / 奖励 / 剧情和世界连起来 |

## 游戏循环（第一版）
- 街区北端有**关卡首领**（= 主线下一关）：打赢推进主线并拿首通奖励（含剧情）；已全通则可重复挑战。
- 街区里有 6 队**巡逻野怪**（= 当前已通的最高关）：靠近会追；打赢拿小鱼干 / 经验（每天 40 场有奖励），90 秒后刷新。
- 4 个**宝箱**（每天刷新一次）、1 位**向导 NPC**（嫦喵，给提示）。
- 输了：队伍回到出生点，野怪冷却。

## 路线图
1. ✅ 引擎 + 第一个街区 + 队伍操控 + 遭遇战 + 奖励
2. 画面提升：湿地面反射、远景都市 / 全息广告牌 / 飞行器、蒸汽与脏污、色彩分级、AI 贴图接入
3. 更多街区（对应章节主题：集市、赤壁、森林、雾岛、宫殿）+ 区域间传送门
4. 玩法扩展：任务 NPC 链、隐藏宝箱 / 采集点、精英怪、区域 Boss 机制、队伍技能在探索中的用法（猫爪印地图技能）
5. 战斗也搬进 3D 场景（现在是浮层里的 2D 背景 + 3D 猫）

## 性能预算（软件渲染下量的，真机待测）
- 绘制调用 ≈ 281（关阴影），开阴影 ≈ 695；三角面 ≈ 31 万。手段：静态景物合批（纯色材质统一成顶点色、同风格楼共用立面材质）、猫描边烘焙进顶点、飞行器 Instanced、蒸汽 Points、远处的猫隐藏。
- `WorldView` 有自适应画质：连续掉帧（平均 < 30fps）依次关雨 → 阴影 → 泛光 → 降分辨率。
- 新增道具请遵守 `docs/CODEX_WORLD_BRIEF.md` 的约束（缓存材质、≤40 网格），合批会替你处理其余。

## 已验证的流程（浏览器里自动化跑过）
遇野怪 → 战斗浮层 → 胜利奖励；碰首领 → 战斗 → 通关弹窗 → 主线推进 1-1 → 1-2；**战败**（1 级队伍打 4-21）→ 战败弹窗「战力 483，推荐 2,033」→ 无报错；乱点测试（含探索页）无报错。（软件渲染下一场战斗要几分钟，真机会快得多。）

## 操作
- 点地面 / 点实体：A* 寻路走过去；拖动旋转镜头，双指缩放。
- 左下虚拟摇杆、桌面 WASD / 方向键：相对镜头朝向直接移动，撞墙沿墙滑行（`Explorer.push`）。
- 遭遇战用圆形转场（`arenaFight` 的 banner 参数）；战斗背景是 `WorldView.backdrop()` 从街面高度拍的当前街景（隐藏小猫和头顶标签），战斗本身仍是 2D 浮层 + 3D 小猫离屏渲染。
- 嫦喵的每日委托（`src/game/explore.ts`）：击败 5 只野猫 / 打开 3 个宝箱 / 赢 1 场首领战，三项完成后找嫦喵领奖（小鱼干 + 经验 + 6 猫薄荷 + 40 金铃铛，每天一次，5 点刷新）；进度显示在探索界面左侧。
- 探索音效：雨声环境音、猫爪脚步、野怪发现警示音（`src/app/sfx.ts`，程序合成）。
- 猫薄荷丛：每个街区 3 丛（`DEFAULT_HERBS`，摆在马路上），走近采集，每天每丛一次，给 3~5 猫薄荷 + 少量小鱼干；不计入「打开 3 个宝箱」委托。
- 探索足迹（`TRAIL`）：击败野猫 / 开宝箱 / 采猫薄荷 / 赢首领战的长期累计目标，各 3~4 档，够数后在「足迹」弹窗手动领取（小鱼干 + 经验，高档带猫薄荷与金铃铛）；累计不受每日上限影响，隔天不清零。

## 性能预算（实测，软件渲染下数三角面，桌面带阴影）
- 3D 小猫是三角面大头（每只 3~4.5 万，约一半是描边外壳）。探索世界里的猫用 `detail.k = 0.6` 降细分（`art3d/toon.ts` 的 `detail`），战斗与立绘保持满细节；只有玩家队伍投射实时阴影，其他猫用脚下的假阴影；距队长 46 单位以外的实体不渲染。
- 真实探索画面：2.41M → 0.77M 三角面、790 → 614 次绘制。手机上阴影默认关，实际负担更小。
