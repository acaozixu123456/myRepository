# 背包与存档

背包追加在 `PlayerState.inventory`，子结构版本为 `v: 1`；玩家存档版本与 `maoguozhi.save.v1` 键保持兼容。旧存档缺少背包时补空库存，不给正式玩家发放演示装备。`rich=1` 才补足二十件演示装备、少量素材和已拥有英雄碎片，连续调用不累加，也不重置装备等级与穿戴。

## 库存口径

| 道具 id | 唯一账本 |
| --- | --- |
| `fish` / `bells` | `res.fish` / `res.bells` |
| `catnip_small` | `res.catnip`，每份仍为 500 点成长经验 |
| `recruit_ticket` | `res.tickets` |
| `yarn_small` | `res.yarn`，兼容旧毛线球数量 |
| 其他目录道具 | `inventory.items[id]` |

中、高阶猫薄荷仍是独立道具，不在背包使用操作中折算或消费。英雄专属碎片继续保存在 `heroes[id].shards`，没有建立第二份数量。增删数量须为安全正整数；不足、超堆叠上限或未知引用均失败且不产生部分收支。单批装备最多登记 9,999 件，可分批添加。

装备是独立实例 `{uid, equipId, level, heroId?}`。同名两件可以分别强化；一件仅属于一只猫，同一只猫同部位最多穿一件。新件穿入同槽时自动卸下旧件，也可以直接从另一只猫转移。不改变英雄上阵或下阵状态；`state.equip/unequip` 仍管理阵容。穿戴件须先卸下才能从库存删除。

加载时丢弃未知道具和装备，修复坏编号或重复编号、越界等级和无效穿戴者；同英雄同槽冲突保留先登记的穿戴件，其余回到箱中。资源映射道具不在库存内另存一份，既有 `res` 为权威；原有猫薄荷小数不因迁移被舍弃。

## 强化与毛线球

装备属性沿用内容公式：`base + (level - 1) × growth`。强化一次升一级，消耗 `40 × 品质序号 × 当前等级` 条小鱼干；普通到传说的品质序号为 1 至 5。等级上限取 `EquipDef.levelCap`，满级或资金不足不收费。本 Issue 未给强化价格表，这条线性公式是待 Claude 最终评审的原型口径；不另行扣除金铃纺线。

小／中／大毛线球立即领取当前挂机关卡 60／120／240 分钟的小鱼干和成长经验，采用 `game/stage.idleRate`。收益直接加到 `res.fish/res.exp`，沿用 `claimIdle` 的成长经验池口径，不增加铲屎官等级经验，也不改变挂机箱的积累或计时。加速收益不占挂机箱上限；未知球、数量不足、无效关卡或不安全收益失败且不扣球。

## 战斗接入待决

背包负责穿戴存档、装备属性与同一英雄套装件数展示，英雄详情四槽也读取同一库存。当前引擎的 `UnitSetup` 没有独立装备属性输入，四件套特殊效果尚无通用消费契约，因此本 PR 不把不同属性近似成一个统一倍率，也不自行实现引擎触发。装备属性、二／四件套面板累加及特殊效果的战斗接入已在 Issue #25 提出，交由 Claude 确认和实现。
