## 复算与验证

运行 npm run chatlines:week，或 npm run chatlines:week -- --json 获取原始结果。runner在加载真实游戏模块前固定 TZ=UTC；区间始终是2026-10-05至10-11的完整七天，抽样种子为20261005，不读取当前时间，也不改存档或聊天流程。

不同台词按占位符替换后的完整文本计算，非系统口径包含普通聊天与自动庆贺回应。十分钟重复以同句相邻出现的时间差计算，跨作者仍计重复；随机抽池没有历史去重，观察值不能保证任意十分钟零重复。基线主线92646fc同区间为389种非系统完整文本，扩充后648种，达到Issue的600种目标。

20条样本用真实消息id作固定随机评分，取最小20条后按时间展示，没有按正文挑选。只统计已接入 worldFeed 的文本；静态新增主题、NPC专属句和新意图池均不增加此处结果。

tests/chatlines.test.ts 覆盖数量、全表唯一、40字、六种占位符、禁用词、术语、意图顺序、统计边界、随机样本来源，以及在非UTC父进程下调用真实runner的一周结果。工具另做strict/noUnused检查，不新增依赖。

最终门禁：npm run typecheck 与 npm test 通过，34个测试文件共419项，其中新增23项；工具和测试的独立strict/noUnused检查、git diff --check也通过。
