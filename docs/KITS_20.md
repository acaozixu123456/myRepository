# 十二套技能补全（Issue #20）

`KITS_SR` 沿 Issue 指定导出名登记十二只猫，并非只收 SR 稀有度；实际稀有度仍取英雄目录。数据分成三组模块，由 `sr.ts` 汇总，`KITS` 合并后全部二十四只英雄均有手工技能组。

## 沿现有 DSL 的实现边界

- 持续回合通常在状态持有者行动结束时减少，施加者本次行动也计入；全局轮次触发在说明中写作“整轮”。护盾、幻象等自身增益按这一口径设计，水镜路线乙的幻象有实际跨过施放行动的回归测试。
- 木鹿的兽影是即时召兽效果，不是留场单位；个人图腾有上限，蛮同伴任意行动有概率帮助积累。
- 不能直接表达伤害分摊、原生元素减伤、剩余护盾转治疗及跨友方状态共享，分别采用同袍护盾、防御与自疗、条件反击、指定同袍能量和护盾实现。不以近似描述冒充原机制。
- 张爪与貂蝉的击倒接力依赖自身直接击倒触发；持续伤害没有完整来源回调，不能描述成任何敌方睡着都传递。
- 最高攻击目标按当前引擎的基础攻击选择，不含临时增益，相关升级说明已明示。
- 同名状态刷新保留较大强度并延长时间；兀突骨说明明确团团的这一行为，避免暗示较弱增益会覆盖强增益。
- 郭嘉与另一名唤醒者同时响应同伴睡着时，先执行者可使同伴醒来；郭嘉机会仍被消耗，路线甲仍额外治疗。若需要只在确实唤醒成功时消耗机会，建议增加“目标仍睡着／唤醒成功”条件，由 Claude 决定 DSL 扩展。

## 旧六只 SSR 升级范围

Issue 要求对所有 `KITS` 校验恰为 Lv3／6／9，而旧六只 SSR 原本只有关云喵一条 Lv5，其余没有词条。用户及 Claude 的 Issue 回复已确认由本 PR 一并补齐，保留原普攻、绝技基础 effects、被动、双觉醒。关云喵原 Lv5 的整体 +15% 移至 Lv6，并组合机械升级；因此 Lv5 时不再提前获得该倍率，Lv6 开始保留原倍率。

新增词条使用现有状态、条件、计数与被动触发。祝融路线甲会整段替换绝技 effects，其新增升级用被动响应绝技触发，避免被觉醒覆盖。

## 验证与平衡

`tests/kits.test.ts` 检查完整英雄覆盖、技能编号唯一、说明、嵌套状态／阵营／英雄引用、有限数值、三条机械升级、双觉醒与十八只展示一致性。对二十四只猫各跑双觉醒 × 二十个 seed 的 1v3，检验各自绝技实际施放，并在该行动窗口内产生直接伤害或有效治疗，总计 960 场。

`tools/kits-duels.mjs` 提供十二只的一级未觉醒双边 1v1 对照，各面对其他二十三只 × 二十个 seed × 双边，分别统计引擎胜率、击倒胜率与双方存活达轮次上限比例。医者与团队控制的单挑结果不当作整队平衡结论。完整五猫阵容再使用 `npm run balance`，报告观察区间只标出复核线索，不凭感觉修改倍率。

完整五猫阵容报告见 [BALANCE_REPORT_KITS_20.md](BALANCE_REPORT_KITS_20.md)：3,000 场主样本加 2,200 场独立探针，全部二十四只均使用手工技能组，平均 8.80 轮、首绝技 3.08 轮，4.40% 达轮次上限，无法归因的持续伤害为 0。新十二只中水镜为 64.75%、兀突骨为 36.68%，其余在 38%～62% 观察区间。四只原有 UR 也超过区间，阵营与克制探针存在组合差异；报告如实列出，等待 Claude 决定是否另开调整任务，未按胜率硬改数值。

十二个新绝技特效暂用已有回退机制，画面设想列在 `docs/FX_TODO.md`，未修改特效代码。
