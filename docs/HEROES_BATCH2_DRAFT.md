# 第二批猫猫设定与外观提案（待定稿）

本稿按 [Issue #29](https://github.com/acaozixu123456/myRepository/issues/29) 固定表列出十四只，供 Claude 连同技能草稿评审。正文的蜀族数量与固定表有差异，最终名单和数量仍沿[已有提问](https://github.com/acaozixu123456/myRepository/issues/29#issuecomment-6106108296)确定；此处列出十四只不代表已经注册为产品英雄。

设定采用首批英雄的轻松、温暖、冷幽默口径。外观只引用实际存在的款式；本稿按当前明确口径处理马超的素色无金光 SR 披风，以及赵云的现有长枪。姜维的既有款式近似已获 Issue 明文许可。已明确可用的近似直接采用，武器名与实际形状的差异如实保留；缺款式沿已有提问等待答复，不重复确认。

斧、双钩、拂尘、蝴蝶纹与二色玳瑁纹仍沿上述外观提问等待答复。主线已新增 `slingshot` 弹弓款式，但单个武器栏尚不能同时绘出骨朵与弹弓。技能效果与缺少的 DSL 能力见[已有技能提问](https://github.com/acaozixu123456/myRepository/issues/29#issuecomment-6106216361)，人物背景不作为未实现战斗能力的承诺。

款式核对依据：`src/art/types.ts`、`src/art/gear.ts`、`src/art/garments.ts`、`src/art/weapons.ts` 与 `src/art/cat.ts` 的真实绘制。

以下五份已有完整外观附上“可用款式提案实绘”：头像沿游戏现有头像视窗，全身沿设定集的完整视窗，均由原 `catSvg` 输出。图片只展示提案，不注册英雄；最终名单仍待 Claude 明确。SR 使用素银边，没有金光或光眼。

`wei_zhangliao`｜魏 · 先锋 · SSR｜原型：张辽

品种：灰蓝短毛猫；年龄与体型：壮年 · 精瘦矫健；喜欢：窄桥上的风、利落的双刃、安静点兵。

背景（92 字）：逍遥津的桥口只够几条尾巴并肩，他偏能从中寻出路来。点兵时话不多，总把最窄的一段留给自己；同伴少了，脚步反而更利落。凯旋后众猫夸他胆大，他却认真纠正：桥不宽，喊得太响会把睡着的船夫吵醒。

- **外观缺口与范围**：准确双刀外形与现有双剑的差异已在 Issue #29 提问；本稿不把双剑称作已实现的双刀款式，也不另起审批。
