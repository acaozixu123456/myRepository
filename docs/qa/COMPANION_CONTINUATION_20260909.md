# Companion v3 continuation

Independent candidate only. No production promotion.

This revision activates the prepared compact native tutor prompt, removing polite offers in place of actual help. Normal native audio still uses the complete default conversation; no detached SAY planner is restored. The beginner probe explicitly reviews word/fragment input, a later sentence, a correction, Chinese language questions and a current-turn help request. Automated kana/length/transport checks are labelled mechanical; actual utterance review remains required.

News lookup is now discovery only. An allowed publisher page must be fetched, have a recent publication date (not crawl/modification date), and yield actual title and body/description text. Candidate fact anchors must exactly match that publisher excerpt. Chinese title/background and Japanese question receive a separate source-alignment check. Unavailable pages, dates, unacceptable promotional subjects or failed checks produce news_unavailable; cached non-news conversation remains independent. This is stronger provenance, not a guarantee of every fact or interpretation. No arbitrary source fetch, redirect to unapproved host, or user-provided credentials.

Phone-only UI and explicit mute are unchanged. The earlier ten-turn synthetic probe demonstrated context retention but also produced verbose answers and an unhelpful help offer; its PASS was transport-only and must not be relabelled full quality acceptance.
