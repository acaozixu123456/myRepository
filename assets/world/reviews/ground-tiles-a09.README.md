# A09 审图方法

所有审图读取最终交付的 RGB sRGB ICC WebP；没有重新绘制、边缘融合、偏移遮罩或错开重复。

## 总览

`ground-tiles-a09.webp` 为 **2048×1024**，上行为 `ground_tile_slate_01`，下行为 `ground_drain_slate_02`。每行从左到右为单张、真实直接 2×2 平铺、真实直接 4×4 平铺。每个画面为 448²；先以最终 1024² 图完整重复，再 Lanczos 降采样到展示大小。重复画面内部没有留缝，画面外保留标签与说明区域。总览以 WebP 质量 88、method 6 编码并嵌入 sRGB ICC。

## 成品四边与四角 1:1

两张 `ground_*_slate_*-native-edges.webp` 均为 **2048×1024**，未缩放成品局部像素。位置如下（坐标为零起点、半开区间）：

| 审图区域 | 坐标 / 尺寸 | 成品局部拼接 |
| --- | --- | --- |
| 左侧 | x=0…512，y=0…1024，512×1024 | 成品右 256 列 + 左 256 列；中央 x=256 为横向重复边界 |
| 中上 | x=512…1536，y=0…512，1024×512 | 成品底 256 行 + 顶 256 行；中央 y=256 为纵向重复边界 |
| 右上 | x=1536…2048，y=0…512，512² | 左上放原图右下角，右上放左下角，左下放右上角，右下放左上角；中央为四片交点 |

其余空间只用于标签。局部来源是最终 WebP 解码像素；审图本身为质量 90、method 6 的有损 WebP，空间尺度是成品 1:1，显示时请以原始尺寸查看。成品、审图的文件哈希及尺寸记录在 [A09 出处](../ground/ground-tiles-a09.provenance.json)。

原生 1254² 候选及 lossless PNG 诊断拼图保留在工作空间，未作为游戏素材提交。该审图验证素材重复与微观边界，不是引擎接入截图；本批未改变引擎。
