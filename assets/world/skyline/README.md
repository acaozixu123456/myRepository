## 出处与导出

`image_gen.imagegen` 生成两张初稿，选择第 2 张的楼群层次与克制灯光。将原图横向精确循环移位半个宽度，使原左右接缝移到中央，再由同一图片生成工具局部修复天空、雾和城市衔接。交付采用修复后的第 3 候选，构图保持该移位版本。所有绘画和接缝修复均来自 AI；循环移位只改变像素坐标，没有手工涂改。

实际原生尺寸为 **1774×887**。为满足工作单的 2048×1024，采用等比 Lanczos 上采样约 **15.44%**；交付尺寸与原生尺寸分别记录。导出没有裁切、补边、调色或锐化，嵌入标准 sRGB ICC profile。完整实际提示词、原生文件标识 / SHA256、循环移位输入及 AI 编辑参考、候选选择与成品哈希见 [出处记录](skyline-a07.provenance.json)。原始生成文件保留在本次工作区。
