# EXTRA 武圣与独眼猛将：独立 QA（source7）

结论：可提交审核，保留下面明确的覆盖程度与表面接触限制。独立冻结副本的 400 个有限姿势/时间/朝向样本未发现新增**可见**开放眼或鼻口遮挡、非意图的配饰实体穿头/穿口鼻、或取景加重。这里没有把所有原始遮挡 ID 说成零，也没有把有限采样等同于任意动画时刻的证明。

对象只有两位真实英雄：`shu_guanyunmiao` 的 `beardLong + redFace`，以及 `wei_xiahoudun` 的 `eyepatch`；没有杂兵或宠物使用这三种配饰。实际看过两张 [关云喵参考](../../../../../assets/heroes/ref/shu_guanyunmiao.jpg) / [夏侯墩参考](../../../../../assets/heroes/ref/wei_xiahoudun.jpg)，并读 `ART_PROMPTS.md`。黑色三绺长须、砖红面色和深皮眼罩在原生三姿势里可以辨认，配色符合对应参考。

## 遮挡、覆盖与取景

开放眼新增原始 ID **496**（64 用例）：夏侯墩 index0 为 390，关云喵两眼为 106。逐 ID 对照最前面的剩余猫身三角形，496 点的眼核都早已被实际 head 遮住，因此新增可见开放眼遮挡为 **0**。候选红色贴层或绑带本身可能位于头表面前方；本结论指原先看不到的眼点，不是把配饰统称为隐藏在头后。

含有意遮盖的夏侯墩 index1 时，原始新增眼 ID 总数为 4751。额外保存的 13,154 条眼罩遮挡 owner 映射都落在同一 `extra-sewn-eyepatch` 的 mask/rim/link/rivet/band 及描边，未将其它配饰误当眼罩允许。五个鼻口标记新增 ID 为 0；活动口 3×3 仅在夏侯墩 hurt/t=0.4/148° 新增 `mouthO:0,2` 与 `mouthO:1,2`，二者均被实际头部提前遮住，可见新增为 0。

source5 曾在夏侯墩 slump/t=0.4/+32° 挡住真实 `muzzleL`。source7 对同一实际点重新投射：head-local `[-0.18724327328656107,-0.07907111721447448,0.5977716422576517]`，候选配饰命中为 null，原先 rim/mask 遮嘴已消除；正常旧/新截图也复核了这个位置。

**最不满意的地方是眼罩外白边覆盖不完整。** 正常 idle/windup/strike 图中瞳孔与眼中心被盖住，少量外白边仍可露出。夏侯墩 200 个有限样本中，73 用例合计 1083 个原本可见的眼核格点未被眼罩盖住；idle/t=0.4/+32° 有 21 点。格点是眼核投影包围框采样，不能直接称为白眼像素或虹膜中心；hurt/+32° 的 `(5,5)` 格也有一处露出，额外正常烘焙图看见的是窄边。这里不承诺整个白眼或全部眼三角形被遮住。这是本次已接受的覆盖程度，与另一只开放眼新增可见遮挡 0 分开；再次扩大下沿会重新引入真实口鼻遮挡。

配饰自己的 FRAME 出界 0，整猫旧/新都是 **8** 条出界，所有裁切幅度相同：关云喵 castFwd 与 guard，t=0.4，各四朝向；既有 paw 越过下边界分别 `0.040644194144251244` / `0.03330679079714338`。因此不是“全部整猫都在框内”。FRAME 为 x=[−2.2,2.2]、y=[−0.25,3.6]；不将这个模型结论推广成战斗舞台或演员互相无遮挡。
